knip 도달 가능성 explorer

knip은 파일을 entry에서 도달 가능한 것의 여집합으로 판정한다(익스포트는 다른 규칙). 노드를 누르면 entry → 그 파일까지의 import 도달 경로가 펼쳐진다

모듈 import 그래프에서 노드를 선택하면 entry로부터의 import 도달 경로를 보여주고, entry를 끄면 경로가 사라져 멀쩡한 코드가 거짓 미사용으로 잡힘을 드러내는 explorer.

entry E: index plugin (config) 깊이 ▸

노드 클릭 = 도달 경로 보기 · 깊이 = entry에서 import를 따라간 단계 수 · entry를 끄면 경로가 끊긴다

판정 미사용 파일 = 전체 \ R — entry에서 도달 못 하는 모듈
도달 entry에서 출발 → import를 한 줄씩 따라가며 R을 넓힌다
깊이 import를 몇 단계 따라갔나 (entry에서의 거리)
함정 entry를 빠뜨리면 R이 줄어 멀쩡한 코드가 거짓 미사용으로 잡힌다
