`verbatimModuleSyntax` 를 켜면 `type` 없는 import 는 출력에 그대로 남는다 — 타입만 가져올 땐 `import type` 으로 표시해야 한다(안 하면 TS1484).[^verbatim]

```ts
import type { A } from 'a'
```
