![verbatimModuleSyntax 를 켜면 컴파일러가 import 가 타입으로만 쓰이는지 추측하지 않는다. type 표시가 없는 import 는 출력 JS 에 그대로 남고, type 표시가 있는 것만 통째로 지운다. 그래서 타입만 가져올 땐 import type 으로 적어야 한다 — 안 그러면 런타임에 없는 값을 import 하게 되어 TS1484 에러가 난다. 기존 코드는 fix-verbatim-module-syntax 로 자동으로 고친다.](/svg/verbatim_module_syntax.svg)

```haskell
-- verbatimModuleSyntax: 쓰임새를 추측하지 않고 표시대로만 지운다
emit :: Import -> Maybe Import
emit (Import Type _) = Nothing      -- import type { A } — 통째로 지운다
emit i               = Just i       -- type 없는 import 는 그대로 남는다

-- 그래서 타입만 가져올 땐 표시해야 한다 (안 하면 TS1484)
import type { A } from 'a'
-- 기존 코드 일괄 수정: fix-verbatim-module-syntax
```
