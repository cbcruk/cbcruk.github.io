![입력란 두 개에 값을 넣고 로그인 버튼을 누르면 onSubmit 이 불린다. 테스트용 핸들러 안에서 preventDefault 한 뒤 new FormData(e.target) 를 Object.fromEntries 로 객체로 바꿔 기대값 { username, password } 와 비교하고, 바깥에서는 핸들러가 불렸는지만 확인한다.](/svg/form_submit_formdata.svg)

```haskell
-- 폼 제출 테스트: 핸들러 안에서 FormData 를 객체로 바꿔 비교한다
submitted :: Form -> Map Name Value
submitted = fromEntries . entries . formData        -- new FormData(e.target) → Object.fromEntries

test = do
  change "아이디" "testuser" ; change "비밀번호" "password" ; click "로그인"
  submitted form `shouldBe` fromList [("username", "testuser"), ("password", "password")]
  handleSubmit `shouldHaveBeenCalled` ()            -- preventDefault 는 핸들러 안에서
```
