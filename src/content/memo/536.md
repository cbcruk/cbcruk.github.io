![같은 세 단계(fetch → process → display)를 콜백은 안으로 중첩하고, Promise 는 then 으로 옆으로 잇고, async/await 는 위에서 아래로 쓴다. then 에 넘긴 함수가 값을 돌려주면 Promise 로 감싸고(map), Promise 를 돌려주면 풀어서 잇는다(flatMap). 한 메서드가 둘 다 해서 Promise 안의 Promise 는 만들어지지 않는다.](/svg/promise_then_map_flatmap.svg)

```haskell
-- 콜백 → Promise → async/await: 같은 세 단계를 쓰는 세 가지 방법
callback = fetchData (processData (displayData))     -- 안으로 중첩
chain    = fetchData >>= processData >>= displayData  -- then 으로 옆으로
main = do                                             -- 위에서 아래로
  d <- fetchData
  p <- processData d
  displayData p

-- then 은 모나드의 >>= 와 map 을 한 메서드로 한다
then :: Promise a -> (a -> b | Promise b) -> Promise b
then p f = case f x of
  Promise q -> q            -- 풀어서 잇는다 (flatMap)
  v         -> resolve v    -- 감싼다 (map)
-- 그래서 Promise (Promise a) 는 만들어지지 않는다 — thenable 도 같은 식으로 푼다
```
