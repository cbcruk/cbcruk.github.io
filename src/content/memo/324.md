![aria-labelledby 는 공백으로 구분한 id 목록을 받아 그 순서대로 각 요소의 텍스트를 이어 붙여 접근 가능한 이름을 만든다. 목록 항목은 라벨 span 과 값 span 을 둘 다 가리켜 "주행거리 10.4만km" 처럼 읽힌다. aria-label 과 함께 있으면 aria-labelledby 가 이긴다. 화면 텍스트를 aria-label 로 또 적어 중복하지 말고 가리킨다.](/svg/aria_labelledby_concat.svg)

```haskell
-- 접근 가능한 이름: aria-labelledby 가 aria-label 보다 우선
name :: Element -> String
name el = maybe (ariaLabel el) (unwords . map textOf) (labelledby el)   -- id 목록 순서대로 이어 붙인다

-- <div role="region" aria-labelledby={titleId}><h2 id={titleId}>제목</h2>
-- <div role="listitem" aria-labelledby={`${label}-label ${label}-value`}>
name item == "주행거리 10.4만km"
-- 화면 텍스트를 aria-label 로 다시 적지 말고 가리킨다 · 추가 설명은 aria-describedby
```
