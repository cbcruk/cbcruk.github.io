![Less 변수는 값만이 아니라 이름 자리에도 들어간다. @primary 는 값, .@{component} 는 선택자, background-@{property} 는 속성 이름, url("@{path}/icon.svg") 는 문자열 안에 보간된다. @@theme 은 theme 의 값("primary")을 이름으로 다시 찾아 @primary 의 값이 된다. 맵(3.5+)은 @colors[primary] 로 꺼낸다. ~"" 는 문자열을 따옴표 없이 그대로 내보낸다 — CSS 변수 이름을 조합할 때 쓴다. @component 에 따옴표를 넣으면 선택자가 .'button' 으로 나온다.](/svg/less_variables.svg)

```haskell
-- Less 변수는 값 자리뿐 아니라 이름 자리에도 들어간다
lookup :: Env -> Name -> Value
color      = lookup env "primary"                     -- @primary
selector   = "." ++ show (lookup env "component")     -- .@{component} → .button (따옴표를 넣으면 .'button')
property   = "background-" ++ show (lookup env "property")   -- background-@{property}
icon       = path ++ "/icon.svg"                      -- url('@{path}/icon.svg')
indirect   = lookup env (show (lookup env "theme"))   -- @@theme → @primary 의 값
fromMap    = lookup (lookup env "colors") "primary"   -- @colors[primary] (3.5+)
escaped    = raw ("--" ++ prefix ++ "-color")         -- ~'…' 따옴표 없이 그대로. CSS 변수 이름 조합에
-- :root { --primary: @primary; } 로 CSS 변수에 넘긴다
```
