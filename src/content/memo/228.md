![CRA 는 바벨 설정을 숨긴다. react-app-rewired 로 start·build·test 스크립트를 바꾸고, config-overrides.js 에서 customize-cra 의 useBabelRc() 를 override 에 넣으면 CRA 의 바벨 설정 대신 .babelrc 를 써서 decorators·class-properties 같은 플러그인이 들어간다. 지금은 CRACO 로 구성하는 편이 맞다.](/svg/cra_rewired_babelrc.svg)

```haskell
-- CRA 는 바벨 설정을 숨긴다 → react-app-rewired 로 끼어들어 .babelrc 를 쓰게 한다
babelConfig :: [Override] -> BabelConfig
babelConfig os | UseBabelRc `elem` os = readBabelRc        -- decorators(legacy) · class-properties(loose)
               | otherwise            = craDefault

-- config-overrides.js: module.exports = override(useBabelRc())
-- scripts: react-app-rewired start | build | test
-- 지금은 CRACO 로
```
