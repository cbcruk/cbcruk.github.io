`useBabelRc()` 가 CRA 의 babel 설정 대신 `.babelrc` 를 쓰게 한다.[^228-1]

```js
// config-overrides.js
const { useBabelRc, override } = require('customize-cra')

module.exports = override(useBabelRc())
```
