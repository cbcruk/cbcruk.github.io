![너비 100 인 면을 각도만큼 기울이면 생기는 높이는 100 × tan(각도) 다. 원래 코드는 빗변을 sin 으로 구한 뒤 피타고라스로 높이를 다시 구하지만 결과는 같다. Math.tan 은 라디안을 받으므로 도(°)에 π/180 을 곱해 넣는다.](/svg/tilted_height_tan.svg)

```haskell
-- 기울어진 면의 높이 = 너비 × tan(각도)
tiltedHeight :: Double -> Double
tiltedHeight angle = 100 * tan (angle * pi / 180)    -- Math.tan 은 라디안

-- 원래 코드는 빗변을 거쳐 돌아간다 — 결과는 같다
-- c = a / sin (90° − angle) ; b = sqrt (c² − a²)
```
