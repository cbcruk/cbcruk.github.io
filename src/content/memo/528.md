![Layout 의 children 에 Header·Content·Footer 가 섞여 들어온다. Children.toArray 로 펼친 뒤 요소이면서 type 이 Header 인 것만, Content 인 것만 골라 각 자리에 넣는다. 요소인지는 react-is 의 isElement 로 보는데, 이 용도에선 React.isValidElement 와 결과가 같아 react-is 가 없어도 된다. react-is 가 필요한 건 memo·forwardRef 처럼 typeof·instanceof 로 구분이 안 되는 타입을 가를 때다.](/svg/children_filter_by_type.svg)

```haskell
-- children 에서 특정 컴포넌트만 골라 자리에 넣는다
filterChildren :: ComponentType p -> ReactNode -> [Element p]
filterChildren t = filter (\c -> isElement c && type' c == t) . toArray

layout children = div [ div ".header"  (filterChildren Header  children)
                      , div ".content" (filterChildren Content children) ]

-- isElement (react-is) == isValidElement (React) — 이 용도엔 react-is 가 필요 없다
-- react-is 가 필요한 건 typeof·instanceof 로 못 가르는 타입: isMemo · isForwardRef
```
