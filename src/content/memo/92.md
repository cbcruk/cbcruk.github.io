`setExtraHTTPHeaders` 호출하기
```js
await page.setExtraHTTPHeaders(headers)
```

인터셉트로 가로채기 — 켜면 모든 요청이 멈추니 헤더를 바꿔 `continue` 로 내보내야 한다.[^92-continue]
```js
await page.setRequestInterception(true)

page.on('request', (request) => {
  const headers = {
    ...request.headers()
  }

  request.continue({ headers })
})
```

[^92-continue]: [HTTPRequest.continue() | Puppeteer](https://pptr.dev/api/puppeteer.httprequest.continue): *"Continues request with optional request overrides."* / [Page.setRequestInterception()](https://pptr.dev/api/puppeteer.page.setrequestinterception): *"Once request interception is enabled, every request will stall unless it's continued, responded or aborted; or completed using the browser cache."*
