![모든 요청에 같은 헤더를 붙이려면 page.setExtraHTTPHeaders 를 부른다. 요청마다 다르게 바꾸려면 setRequestInterception(true) 로 가로채는데, 켜는 순간 모든 요청이 멈추므로 request 이벤트에서 헤더를 고쳐 request.continue({ headers }) 로 반드시 내보내야 한다.](/svg/puppeteer_request_headers.svg)

```haskell
-- 모든 요청에 같은 헤더
-- await page.setExtraHTTPHeaders(headers)

-- 요청마다 고치려면 가로챈다 — 켜면 모든 요청이 멈춘다
onRequest :: Request -> IO ()
onRequest req = continue req { headers = modify (headers req) }   -- continue·respond·abort 중 하나를 꼭
```
