TypeScript 제네릭 기본값 - `<T extends Type = DefaultValue>`. 기본값은 제약을 만족해야 하고, 생략한 인자는 기본값으로 정해진다.[^516-defaults]

```typescript
type SelectProps<T extends 'single' | 'multiple' = 'multiple'> = {
  mode: T
  value: T extends 'single' ? string : string[]
}

const a: SelectProps = { mode: 'multiple', value: ['a', 'b'] } // 기본값 사용
const b: SelectProps<'single'> = { mode: 'single', value: 'a' } // 명시적 지정

// 여러 매개변수에 각각 기본값
type ApiResponse<
  TData = any,
  TStatus extends 'loading' | 'success' | 'error' = 'loading'
> = {
  data: TStatus extends 'success' ? TData : null
  status: TStatus
}
```

가장 자주 사용되는 케이스를 기본값으로 설정하면 제네릭을 항상 명시하는 번거로움 줄어듦.

[^516-defaults]: [TypeScript 2.3 — Generic parameter defaults](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-2-3.html#generic-parameter-defaults): *"Default types for a type parameter must satisfy the constraint for the type parameter, if it exists."* / *"Unspecified type parameters will resolve to their default types."*
