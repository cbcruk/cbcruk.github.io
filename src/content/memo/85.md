![Apps Script 의 Maps.newGeocoder() 에 setLanguage("ko") 로 언어를 정하고 reverseGeocode(위도, 경도) 를 부르면 그 좌표의 주소 후보들이 results 로 온다. 각 결과에서 formatted_address 와 geometry.location 의 lat·lng 를 꺼낸다.](/svg/apps_script_reverse_geocode.svg)

```haskell
-- Apps Script: 좌표 → 주소 후보들
reverseGeocode :: Lang -> LatLng -> [Address]
reverseGeocode lang ll = map pick (results (geocode lang ll))   -- Maps.newGeocoder().setLanguage('ko').reverseGeocode(lat, lng)
  where pick r = Address (formattedAddress r) (lat (location r)) (lng (location r))

reverseGeocode "ko" (40.758577, -73.984464)
```
