![스크립트 문자열을 text/javascript Blob 으로 만들고 URL.createObjectURL 로 URL 을 얻어 script 의 src 로 넣는다. CSP 때문에 인라인 textContent 가 막힌 페이지에서도 된다(Firefox 58+). 다만 textContent 는 동기로 바로 돌지만 src 는 내용을 가져온 뒤에야 도는 비동기라, 주입한 코드가 쓸 초기화가 먼저 준비돼 있어야 한다.](/svg/blob_url_script_inject.svg)

```haskell
-- CSP 로 인라인이 막힌 페이지에 Blob URL 로 스크립트를 넣는다 (Firefox 58+)
inject :: String -> IO ()
inject code = do
  u <- createObjectURL (Blob [code] "text/javascript")
  s <- createElement "script"
  setSrc s u >> append body s >> remove body s >> revokeObjectURL u

-- textContent = 동기(즉시), src = 비동기(가져온 뒤)
-- → 주입한 코드가 기대는 초기화는 그 전에 준비돼 있어야 한다
```
