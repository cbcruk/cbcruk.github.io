![Windows 에서는 ActiveXObject("Excel.Application") 로 실행 중인 Excel 을 COM 객체로 잡는다. Node 에서는 node-activex 가 같은 일을 한다. 그다음은 Excel 객체 모델을 따라 내려간다 — Application 에서 Workbook, Worksheet, Range 순. Excel View 는 이렇게 활성 셀의 행 전체를 읽어 별도 창에 띄운다.](/svg/excel_activex_object_model.svg)

```haskell
-- Node 에서 Excel: COM(ActiveX) 으로 실행 중인 앱을 잡고 객체 모델을 따라 내려간다
activeX :: ProgId -> IO Application         -- new ActiveXObject('Excel.Application') · node-activex

-- Application → Workbooks → Worksheets → Range
activeRow :: IO Range
activeRow = entireRow . activeCell <$> activeX "Excel.Application"   -- Excel View: 활성 셀의 행을 별도 창에
```
