![두 박스의 가로 스크롤을 비율로 맞춘다. box1 을 스크롤하면 box1 의 비율(scrollLeft ÷ 스크롤 가능 폭)을 box2 의 폭에 곱해 box2.scrollLeft 에 넣는다. 그러면 box2 에도 scroll 이벤트가 오는데, 그건 넣는 순간이 아니라 다음 렌더링 때 온다 — 그래서 isSyncing 처럼 동기로 켰다 끄는 플래그는 이벤트가 올 때 이미 꺼져 있어 되먹임을 못 막는다. 대신 다음에 올 이벤트 하나(ignore = box2)를 표시해 두고 그 이벤트에서 지운다. 넣을 값이 지금 값과 같으면 이벤트가 안 오므로 표시도 하지 않는다 — 표시하면 다음 사용자 스크롤을 삼킨다.](/svg/scroll_sync_ignore_next.svg)

```haskell
-- 두 요소의 가로 스크롤을 비율로 맞춘다. 서로 리스너를 건다
sync :: Box -> Box -> Ignore -> (IO (), Ignore)
sync source target ignore
  | ignore == Just source       = (pure (), Nothing)        -- 내가 일으킨 이벤트 하나를 건너뛴다
  | scrollLeft target == next   = (pure (), ignore)         -- 값이 같으면 이벤트도 안 온다 — 표시하면 다음 사용자 스크롤을 삼킨다
  | otherwise                   = (scrollLeft target := next, Just target)
  where ratio = scrollLeft source / (scrollWidth source - clientWidth source)
        next  = round (ratio * (scrollWidth target - clientWidth target))

-- 동기 플래그로는 못 막는다: scroll 이벤트는 넣는 순간이 아니라 다음 렌더링에 온다
isSyncing := True >> scrollLeft target := next >> isSyncing := False   -- 이벤트가 올 때 이미 False
```
