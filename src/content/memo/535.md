![Just 10 에 bind 로 safeDivide _ 2 를 이으면 Just 5 가 된다. safeDivide _ 0 을 이으면 0 으로 나눌 수 없어 Nothing 이 되고, 그 뒤에 무엇을 bind 해도 함수를 부르지 않고 Nothing 이 그대로 흐른다. 중간마다 null 검사를 쓰지 않아도 실패가 끝까지 전파된다.](/svg/maybe_bind_shortcircuit.svg)

```haskell
-- TypeScript 로 Maybe 를 만든다: Just·Nothing 두 클래스에 bind 하나씩
data Maybe a = Just a | Nothing

bind :: Maybe a -> (a -> Maybe b) -> Maybe b
bind (Just x) f = f x        -- class Just    { bind(fn) { return fn(this.value) } }
bind Nothing  _ = Nothing    -- class Nothing { bind(fn) { return this } } — fn 을 안 부른다

safeDivide :: Double -> Double -> Maybe Double
safeDivide _ 0 = Nothing
safeDivide x y = Just (x / y)

Just 10 `bind` (`safeDivide` 2) == Just 5
Just 10 `bind` (`safeDivide` 0) == Nothing
```
