!["자바스크립트" 를 한 글자씩 치는 동안 입력 이벤트가 연달아 온다. debounce(300ms) 는 입력이 300ms 멈춘 뒤 마지막 값으로 한 번만 검색한다 — 검색어 필터링 UI 에 맞다. throttle(1초) 은 계속 치는 동안에도 1초에 최대 한 번씩 검색해 결과를 실시간으로 보여주면서 요청 수를 묶는다.](/svg/debounce_vs_throttle.svg)

```haskell
-- 검색어 필터링 UI → debounce (300~500ms): 다 친 뒤에 한 번
-- 타이핑 완료 후 검색이 더 자연스럽다. "자바스크립트" 를 칠 때 매 글자마다 검색하면 비효율적이다
debounce :: Duration -> (a -> IO ()) -> (a -> IO ())   -- 호출이 멈출 때까지 기다려 마지막 하나만
throttle :: Duration -> (a -> IO ()) -> (a -> IO ())   -- 계속 호출돼도 최대 빈도로

handleSearch = debounce 300 performSearch
onInput e    = handleSearch (value (target e))

-- "자바스크립트" 를 치면
calls (debounce 300 search) == ["자바스크립트"]
calls (throttle 1000 search)   -- 1초에 최대 1회 — 실시간 결과를 보이면서 요청을 묶을 때
```
