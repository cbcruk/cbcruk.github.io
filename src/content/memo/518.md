검색어 필터링 UI → **Debounce** (300-500ms)

타이핑 완료 후 검색이 더 자연스러움. "자바스크립트" 입력 시 매 글자마다 검색하면 비효율적. Debounce 는 호출이 멈출 때까지 기다리고, Throttle 은 계속 호출돼도 정해진 최대 빈도로 실행한다.[^518-debounce]

```javascript
const handleSearch = debounce((term) => performSearch(term), 300)
input.addEventListener('input', (e) => handleSearch(e.target.value))
```

Throttle은 실시간 검색 결과를 보여주면서 요청 제한할 때 사용 (1초마다 최대 1회 등).

---

[^518-debounce]: [Debounce - MDN Glossary](https://developer.mozilla.org/en-US/docs/Glossary/Debounce): *"The key difference is that throttling enforces limits on continuous operations, while debouncing waits for invocations to stop for a specific time to consolidate many noisy invocations into one single invocation."*
