![파일 이름 앞부분을 떼어 일괄 rename 한다. for f in *.md 를 돌며 mv "$f" "${f#* }" — "351 529.md" 는 앞에서 "* " 에 맞는 가장 짧은 부분 "351 " 이 지워져 "529.md" 가 된다. 규칙: # 은 앞에서, % 는 뒤에서 지우고, 하나면 가장 짧게, 둘이면 가장 길게 맞는 부분을 지운다. x="a.b.c" 면 ${x#*.} 는 b.c, ${x##*.} 는 c, ${x%.*} 는 a.b, ${x%%.*} 는 a. 변수는 따옴표로 감싼다 — 없으면 공백에서 단어가 갈려 mv 가 깨진다.](/svg/bash_param_expansion.svg)

```haskell
-- 파일 이름 앞부분("351 ")을 떼어 일괄 rename
main = mapM_ (\f -> mv f (f # "* ")) =<< glob "*.md"   -- for f in *.md; do mv "$f" "${f#* }"; done

-- 매개변수 확장: 어느 쪽에서, 얼마나
(#), (##), (%), (%%) :: String -> Glob -> String
x #  p = dropShortestPrefix p x      -- ${x#p}   # 은 앞 (키보드에서 $ 왼쪽)
x ## p = dropLongestPrefix  p x      -- ${x##p}
x %  p = dropShortestSuffix p x      -- ${x%p}   % 는 뒤
x %% p = dropLongestSuffix  p x      -- ${x%%p}
-- ${x/old/new} 첫 번째 치환 · ${x//old/new} 전체 치환

"a.b.c" # "*." == "b.c" ;  "a.b.c" ## "*." == "c"
"a.b.c" % ".*" == "a.b" ;  "a.b.c" %% ".*" == "a"

-- JS 로 치면: for...of → for…in…do…done · split(' ')[1] → ${f#* } · replace() → ${f/old/new} · fs.rename → mv

-- 따옴표: 없으면 공백에서 단어가 갈린다
words "351 529.md" == ["351", "529.md"]   -- mv $file … 가 인자 셋이 된다
-- 디버깅: set -x (실행 명령 출력) · set -e (에러에서 중단)
```
