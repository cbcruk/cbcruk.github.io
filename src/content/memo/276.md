![빌드 결과의 소스맵을 git 커밋 해시를 release-version 으로 붙여 datadog-ci 로 Datadog 에 올린다. 올린 뒤에는 build 에서 .map 파일을 지운다 — Datadog 은 이미 받아 두었으니 스택을 풀 수 있고, 브라우저에는 원본 소스가 노출되지 않는다.](/svg/datadog_sourcemap_upload_rm.svg)

```haskell
-- 소스맵: Datadog 에 주고, 브라우저에는 안 준다
deploy :: Build -> IO ()
deploy build = do
  v <- gitShortHash                                     -- --release-version
  upload Datadog (maps build) v                         -- datadog-ci sourcemaps upload ./build --service --minified-path-prefix
  rm (maps build)                                       -- 이미 받았으니 배포물에선 지운다
```
