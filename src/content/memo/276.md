올린 뒤 배포물에서 지운다 — Datadog은 이미 받았고[^276-upload] 브라우저에는 노출되지 않는다.

```sh
VERSION=$(git log --pretty=format:'%h' -n 1)

yarn datadog-ci sourcemaps upload ./build \
  --service "$SERVICE" \
  --minified-path-prefix "$MINIFIED_PATH_PREFIX" \
  --release-version "$VERSION"

rm ./build/static/js/*.map
```

---

[^276-upload]: [Upload JavaScript Source Maps - Datadog](https://docs.datadoghq.com/real_user_monitoring/guide/upload-javascript-source-maps/#service-and-version): *"It scans the dist directory and subdirectories to automatically upload source maps with the relevant minified files."*
