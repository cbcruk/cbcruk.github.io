![2025-10-28(화)이 든 주를 구한다. startOf(isoWeek) 는 ISO 8601 이라 월요일 10-27 부터 일요일 11-02 까지다 — 캘린더 UI 에 주로 쓴다. startOf(week) 는 로케일을 따라 기본 en·ko 에선 일요일 10-26 부터, en-gb 에선 월요일부터다. 시작일에 0~6일을 더해 7개를 만든다.](/svg/dayjs_week_days.svg)

```haskell
-- 특정 날짜가 든 주의 7일
weekDays :: Bool -> Date -> [Date]
weekDays iso d = [start `addDays` i | i <- [0..6]]
  where start = startOf (if iso then IsoWeek else Week) d
-- IsoWeek: ISO 8601, 월요일 시작 (캘린더 UI 에 주로) — dayjs.extend(isoWeek) 필요
-- Week:    로케일을 따른다 — 기본 en·ko 는 일요일, en-gb 는 월요일

weekDays True "2025-10-28" == ["2025-10-27", …, "2025-11-02"]
```
