![JSON.stringify 는 열거 가능한 자기 속성만 보므로 Set·Map 은 {} 가 된다. 두 번째 인자 replacer 로 값이 Set 이면 배열로 바꿔 넣는다. 세 번째 인자 space 에 문자열을 주면 그것으로 들여 쓰는데, 10자에서 잘린다.](/svg/json_stringify_replacer.svg)

```haskell
-- JSON.stringify 는 열거 가능한 자기 속성만 — Set·Map 은 {} 가 된다
replacer :: Key -> Value -> Value
replacer _ (SetV s) = ArrayV (toList s)     -- value instanceof Set ? [...value] : value
replacer _ v        = v

-- JSON.stringify(dude, replacer)
-- JSON.stringify(dude, null, "🍆")         -- space 문자열로 들여쓰기 — 10자에서 잘린다
```
