![스트리밍 영상을 youtube-dl 로 받을 때 403 이 나면 영상 접근이 특정 도메인(Referer)으로 제한된 경우다. --referer 에 영상이 실린 페이지 URL 을, --user-agent 에 브라우저 UA 를 주면 받아진다. 자주 쓰면 페이지 URL 을 그대로 referer 로 넘기는 함수로 둔다.](/svg/ytdl_referer_403.svg)

```haskell
-- 403: 영상 접근이 특정 도메인(Referer)으로 제한됐다
fetch :: Url -> Maybe Referer -> Either Status Video
fetch url Nothing  = Left 403
fetch url (Just r) = Right (download url)

-- dmRef() { youtube-dl $1 --referer $1 --user-agent "UA" }
dmRef :: Url -> IO ()
dmRef url = youtubeDl url ["--referer", url, "--user-agent", ua]
```
