![zodios 는 응답 검증이 실패하면 ZodError 를 그대로 던지지 않고 ZodiosError 의 cause 에 담아 던진다. 그래서 instanceof z.ZodError 로는 잡히지 않고, ZodiosError 인지 본 뒤 cause 가 ZodError 인지 확인해 fromZodError 로 읽는다.](/svg/zodios_error_cause.svg)

```haskell
-- zodios: 응답 검증 실패를 ZodiosError 로 감싸고 ZodError 는 cause 에 둔다
zodError :: Error -> Maybe ZodError
zodError (ZodiosError { cause = Just (ZodErr z) }) = Just z   -- err instanceof ZodiosError && err.cause instanceof ZodError
zodError (ZodErr z)                                = Just z
zodError _                                         = Nothing
-- instanceof z.ZodError 만 보면 놓친다 → fromZodError(err.cause).toString()
```
