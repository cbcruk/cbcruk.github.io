![모나드는 세 부품이다. 값을 감싸는 타입(로그가 붙은 숫자), 값을 감싸는 함수 unit(로그가 빈 채로 감싼다), 감싼 값에 함수를 이어 붙이는 bind(결과는 새 값, 로그는 앞뒤를 이어 붙인다). Option·Promise 도 같은 모양이고 Promise 에선 then 이 bind 다. 다만 Promise 는 근사다 — then 이 붙은 객체(thenable)를 자동으로 펼쳐서, unit(x) 에 f 를 bind 한 것과 f(x) 가 달라진다(left identity 가 깨진다).](/svg/monad_three_parts.svg)

```haskell
-- 모나드 = 연속된 연산 사이의 처리를 숨기는 패턴. 부품은 셋
data Logged a = Logged { result :: a, logs :: [String] }    -- 1 감싸는 타입

unit :: a -> Logged a                                       -- 2 감싸기 (return)
unit n = Logged n []

bind :: Logged a -> (a -> Logged b) -> Logged b             -- 3 잇기 (flatMap)
bind (Logged x l) f = let Logged y l' = f x in Logged y (l ++ l')   -- 로그 합치기가 숨는다

-- Option·Promise 도 모나드다. Promise 에선 then 이 bind
-- 단 Promise 는 근사다: thenable 을 자동으로 펼쳐 left identity 가 깨진다
unit x `bind` f == f x                                      -- 법칙
v = { then: r => r(42) } ; f x = resolve [x]
(resolve v `then` f) == [42]  /=  f v == [v]
```
