![페이지 안 JS 로 캔버스에서 꺼내거나 서버에서 다시 받는 길이 있고, DevTools 프로토콜로 꺼내는 길이 있다. CDP 는 Page.getResourceTree 로 프레임의 리소스 목록을 얻고 Page.getResourceContent 로 각 리소스의 내용을 받는다(base64 면 디코딩). 또는 page.on("response") 로 응답이 올 때마다 response.buffer() 를 받는다.](/svg/headless_image_extract.svg)

```haskell
-- 헤드리스 브라우저에서 이미지 꺼내기
data Way = InPageCanvas | InPageRefetch | Cdp | OnResponse

images :: Page -> IO [Buffer]
images page = do
  cdp <- createCDPSession page
  tree <- send cdp "Page.getResourceTree"
  forM (resources tree) $ \r -> do
    c <- send cdp "Page.getResourceContent" (frameId tree, url r)
    pure (decode (if base64Encoded c then Base64 else Utf8) (content c))

-- 또는: page.on('response', r => r.buffer())
```
