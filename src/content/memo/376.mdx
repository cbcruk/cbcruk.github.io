![JSON 값은 셋 중 하나다. 기본값(string·number·boolean·null), 문자열 키에 JSON 값을 담은 객체, JSON 값의 배열. 객체와 배열이 다시 JSON 값을 담아 재귀한다. type-fest 의 JsonObject 는 선택 속성이 undefined 일 수 있게 한 겹 더 열어 두고, JsonArray 는 readonly 배열도 받는다.](/svg/json_value_type.svg)

```haskell
-- JSON 값 = 기본값 | 객체 | 배열, 객체·배열이 다시 JSON 값을 담는다
data JsonPrimitive = JString String | JNumber Double | JBool Bool | JNull
data JsonValue     = Prim JsonPrimitive
                   | Obj (Map String JsonValue)   -- type-fest: 선택 속성은 undefined 도 허용
                   | Arr [JsonValue]              -- readonly 배열도
-- 직렬화 결과 타입까지 필요하면 type-fest 의 Jsonify
```
