![목표 시각 "18:30:00" 을 오늘 날짜에 맞춘 Date 로 만들고 지금을 뺀다. Date 끼리 빼면 숫자 문맥이라 둘 다 밀리초 타임스탬프가 되어 차가 밀리초로 나온다. 음수면 이미 지났으니 null. 아니면 3,600,000 으로 나눠 시, 60,000 으로 나눈 나머지 60 이 분, 1,000 으로 나눈 나머지 60 이 초다. 예: 16:14:30 에 부르면 2시간 15분 30초.](/svg/remaining_time_ms.svg)

```haskell
-- 지금부터 목표 시각("18:30:00")까지 남은 시간
remaining :: Time -> Time -> Maybe (Int, Int, Int)
remaining now target
  | diff < 0  = Nothing                                     -- 이미 지났다
  | otherwise = Just ( diff `div` 3600000 `mod` 24
                     , diff `div` 60000   `mod` 60
                     , diff `div` 1000    `mod` 60 )
  where diff = target - now   -- Date − Date: 숫자 문맥이라 둘 다 타임스탬프(ms)가 된다
                              -- target 은 오늘 날짜에 setHours h m s

remaining (today 16 14 30) (today 18 30 0) == Just (2, 15, 30)
```
