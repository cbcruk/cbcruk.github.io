![isUnchecked && … || isChecked && … || 기본값 사슬은 짧지만 상태가 늘면 어떤 조합이 어디로 가는지 읽기 어렵다. 상태를 UNCHECKED·CHECKED·DEFAULT 중 하나인 값으로 두고 switch 하나로 색을 고르면 상태 하나에 색 하나가 대응한다.](/svg/status_to_color.svg)

```haskell
-- 불리언 사슬:  (isUnchecked && A) || (isChecked && B) || C  — 상태가 늘면 조합을 읽기 어렵다
data Status = Unchecked | Checked | Default

color :: Status -> Palette
color Unchecked = "palette.label.alternative"
color Checked   = "palette.primary.normal"
color Default   = "palette.label.normal"
-- 상태를 키로 인덱싱할 땐 키 타입을 좁힌다 (string 으로는 객체를 인덱싱할 수 없다)
```
