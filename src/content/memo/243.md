![new FontFace(family, url) 로 만든 글꼴은 그것만으로는 글자에 쓰이지 않는다. document.fonts 에 add 해야 렌더링에 쓰이고, URL 소스는 검증만 되고 자동으로 받지 않으므로 load 를 불러야 내려받는다. add 와 load 의 순서는 상관없지만 둘 다 해야 한다.](/svg/fontface_add_load.svg)

```haskell
-- new FontFace() 만으로는 글자에 안 쓰인다
usable :: FontFace -> Bool
usable face = added face && loaded face
  -- added:  document.fonts.add(face) — 집합에 있어야 그릴 때 쓰인다
  -- loaded: await face.load()        — URL 소스는 검증만 하고 자동으로 받지 않는다

loader = do
  face <- newFontFace "Material Symbols Outlined" "url(https://fonts.gstatic.com/…woff2)"
  add (fonts document) face
  load face                     -- 순서는 상관없지만 둘 다
```
