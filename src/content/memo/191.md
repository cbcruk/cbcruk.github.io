![속성 키는 문자열이나 Symbol 뿐이라 그 밖의 값은 문자열로 바뀐다. 배열 ['a'] 는 문자열로 'a' 가 되므로 obj[['a']] 는 obj.a 다. 원소가 둘이면 'a,b' 가 되어 다른 키가 된다.](/svg/property_key_coercion.svg)

```haskell
-- 속성 키는 문자열이나 Symbol — 그 밖의 값은 문자열로 바뀐다
key :: Value -> Either Symbol String
key (Sym s) = Left s
key v       = Right (toString v)      -- 숫자·배열·객체 모두

toString ["a"]      == "a"            -- obj[['a']] == obj.a
toString ["a", "b"] == "a,b"
```
