```js
const obj = {
  a: 1,
  b: 2,
}

console.log(obj[['a']]) // 1
console.log(obj[['b']]) // 2
```

이게 되네 🤔 — 속성 키는 문자열·Symbol 뿐이라 배열이 문자열로 바뀐다: `String(['a'])` 는 `'a'`, `String(['a', 'b'])` 는 `'a,b'`.[^191-key]

---

[^191-key]: [Property accessors - MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Property_accessors#property_names): *"Each property name is a string or a Symbol. Any other value, including a number, is coerced to a string."*
