![URL 을 fetch 해 응답을 arrayBuffer 로 받아 Buffer 로 바꾸고, 폴더가 없으면 만든 뒤 URL 경로의 파일 이름으로 저장한다.](/svg/download_image_buffer.svg)

```haskell
-- 이미지 다운로드: 응답을 Buffer 로 받아 파일로
download :: Url -> IO ()
download url = do
  buf <- fromArrayBuffer <$> (fetch url >>= arrayBuffer)
  createDirectoryIfMissing folder                       -- 없으면 mkdir
  writeFile (folder </> takeFileName (pathname url)) buf
```
