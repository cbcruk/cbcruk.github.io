![JSON.stringify(map) 은 열거 가능한 자기 속성만 보므로 {} 가 된다. 그래서 [...map] 으로 엔트리 배열을 만들어 저장하고, 읽을 때 new Map(JSON.parse(data)) 로 되살린다. set·delete 마다 전체를 다시 저장한다. 출처당 5MiB 를 넘으면 setItem 이 QuotaExceededError 를 던진다.](/svg/map_localstorage_entries.svg)

```haskell
-- Map 을 localStorage 에: JSON.stringify(map) 은 "{}" — 엔트리 배열로 왕복한다
save :: Map k v -> String
save = encode . Map.toList                -- JSON.stringify([...map])

load :: Maybe String -> Map k v
load = maybe Map.empty (Map.fromList . decode)   -- new Map(JSON.parse(data))

set k v = modify (Map.insert k v) >> persist     -- 바꿀 때마다 통째로 다시 저장
-- 출처당 5MiB: 넘으면 setItem 이 QuotaExceededError
```
