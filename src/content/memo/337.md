Google Spreadsheet 팝업 — `onOpen` 은 파일을 열 때 도는 예약 이름(단순 트리거)이라 메뉴를 거기서 붙인다.[^337-onopen]

```javascript
function showAlert() {
  const ui = SpreadsheetApp.getUi()
  ui.alert('팝업 창', '표시할 텍스트', ui.ButtonSet.OK)
}

// 메뉴에 추가
function onOpen() {
  SpreadsheetApp.getUi()
    .createMenu('팝업 메뉴')
    .addItem('팝업 띄우기', 'showAlert')
    .addToUi()
}
```

---

[^337-onopen]: [Simple Triggers - Apps Script](https://developers.google.com/apps-script/guides/triggers): *"onOpen(e) runs when a user opens a spreadsheet, document, presentation, or form that the user has permission to edit."* / [Class Ui](https://developers.google.com/apps-script/reference/base/ui): *"Opens a dialog box in the user's editor with the given title, message, and set of buttons."*
