![onOpen 은 사용자가 편집 권한이 있는 스프레드시트를 열 때 저절로 도는 예약 이름(단순 트리거)이다. 거기서 팝업 메뉴를 만들고 항목 팝업 띄우기를 showAlert 함수에 잇는다. 메뉴를 누르면 showAlert 가 ui.alert 로 제목·본문·OK 버튼이 있는 대화 상자를 띄운다.](/svg/apps_script_onopen_alert.svg)

```haskell
-- onOpen 은 파일을 열 때 도는 예약 이름 (단순 트리거) — 메뉴를 거기서 붙인다
onOpen = addToUi (addItem "팝업 띄우기" "showAlert" (createMenu ui "팝업 메뉴"))

showAlert = alert ui "팝업 창" "표시할 텍스트" OK
```
