![youtube-dl 이 업데이트되지 않아 느려져 같은 옵션을 받는 yt-dlp 로 바꿔 쓴다. -a 로 주소 목록 파일을 한꺼번에, -i 로 중간 에러를 건너뛰고, --write-sub --sub-lang ko 로 자막을, --write-auto-sub 로 자동 자막을 받는다. 플레이리스트는 -o 템플릿에 playlist_index 를 넣어 순서를 파일 이름에 남긴다. 평소엔 dm, 오디오만은 da(-x --audio-format mp3) 로 줄여 쓴다.](/svg/ytdl_options.svg)

```haskell
-- youtube-dl 이 업데이트되지 않아 느려졌다 → 같은 옵션의 yt-dlp 로
data Opt = Batch File              -- -a list.txt : 여러 주소 한꺼번에
         | IgnoreErrors            -- -i          : 중간 에러를 건너뛴다
         | Subs Lang               -- --write-sub --sub-lang ko
         | AutoSubs                -- --write-auto-sub
         | Output Template         -- 플레이리스트 순서를 파일 이름에

playlist = Output "%(playlist)s/%(playlist_index)s - %(title)s.%(ext)s"

-- alias dm="youtube-dl" · alias da="youtube-dl -x --audio-format mp3"
```
