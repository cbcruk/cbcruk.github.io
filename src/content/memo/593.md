커스텀 스킴(`myapp://`) 다이얼로그에서 "항상 열기 허용"을 실수로 체크해 되돌리고 싶을 때. **설정 UI 에는 항목이 없다** — 체크는 프로필의 `Preferences` JSON 에 origin 단위로 저장된다.

```json
"protocol_handler": {
  "allowed_origin_protocol_pairs": { "https://example.com": { "myapp": true } }
}
```

`chrome://settings/handlers` 는 이름이 비슷하지만 **웹 프로토콜 핸들러**(`mailto:` 등 사이트가 등록한 것)만 다룬다. 외부 앱 실행 허용과는 별개다.

가장 안전한 길은 사이트 데이터 삭제다. `chrome://settings/content/all` → 해당 사이트 검색 → "데이터 및 권한 삭제". 허용이 origin 단위 사이트 데이터에 묶여 있어 함께 초기화되는 경우가 많다.

안 되면 파일을 직접 고친다. 단 **Chrome 을 완전히 종료**(백그라운드 프로세스 포함)한 뒤다 — Chrome 은 종료 시 메모리 상태를 `Preferences` 에 덮어써서, 실행 중에 고치면 되돌아간다.

| OS      | 경로                                                                |
| ------- | ------------------------------------------------------------------- |
| macOS   | `~/Library/Application Support/Google/Chrome/<Profile>/Preferences` |
| Windows | `%LOCALAPPDATA%\Google\Chrome\User Data\<Profile>\Preferences`      |
| Linux   | `~/.config/google-chrome/<Profile>/Preferences`                     |

재시작 후 다이얼로그가 다시 뜨면 된 것이다. `excluded_schemes` 에 `true` 로 들어간 스킴은 반대로 "차단" 상태이니 차단을 풀고 싶을 때 같이 본다.
