![beforeEach 에서 vi.useFakeTimers 로 Date 를 가짜로 바꾸고 vi.setSystemTime 으로 오늘을 2024-07-20 으로 고정한다. 그러면 isSameDate 는 같은 날짜에 true, 하루 전·후에 false 를 늘 같게 낸다. afterEach 에서 useRealTimers 로 되돌린다. vitest 와 jest 둘 다 내부적으로 @sinonjs/fake-timers 를 쓴다.](/svg/fake_timers_set_system_time.svg)

```haskell
-- 오늘이 바뀌면 결과가 바뀌는 함수: 가짜 타이머로 "오늘" 을 고정한다
isSameDate :: Date -> Bool
isSameDate d = d == today          -- today 는 new Date() — 테스트에서는 setSystemTime 이 정한다

-- beforeEach: useFakeTimers >> setSystemTime "2024-07-20"
isSameDate "2024-07-20" == True
isSameDate "2024-07-19" == False
isSameDate "2024-07-21" == False
-- afterEach: useRealTimers · vitest·jest 둘 다 내부는 @sinonjs/fake-timers
```
