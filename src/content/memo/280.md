![process.env 를 z.object 스키마로 parse 하면 빠지거나 형식이 틀린 값은 앱이 시작할 때 ZodError 로 바로 터진다 — 쓰는 순간이 아니라. 통과하면 결과에는 스키마에 선언한 키만 남고 나머지 환경 변수는 걸러진다. NODE_ENV 처럼 default 를 주면 없을 때 그 값이 들어간다. window 전역도 같은 방식으로 읽는다.](/svg/zod_env_parse.svg)

```haskell
-- 환경 변수를 스키마로: 빠지면 시작할 때 터지고, 선언한 키만 남는다
parse :: Schema a -> Env -> Either ZodError a     -- .parse 는 Left 를 throw

envSchema = object
  [ ("REACT_APP_FEATURE_RECORDS", string)
  , ("NODE_ENV", enum ["development", "test", "production"] `withDefault` "development") ]

ENV    = parse envSchema    processEnv   -- PATH 같은 선언 안 한 키는 strip
WINDOW = parse windowSchema window
```
