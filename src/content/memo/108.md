![텍스트 말줄임은 맥락마다 방법이 다르다. 표 셀에서는 자동 레이아웃의 셀이 내용만큼 늘어나 잘라 낼 경계가 없으므로 overflow·text-overflow·white-space 셋만 주면 아무 효과가 없다. 표에 width 를 주고, 표의 table-layout: fixed 나 셀의 max-width: 0 중 하나를 더한다. fixed 는 열 너비를 표와 col 너비로만 정하고, max-width: 0 은 셀이 내용 기반 너비를 주장하지 못하게 한다(CSS 2.1 이 정의하지 않은 동작이라 브라우저 관행에 기댄다). 표 width 없이 max-width: 0 만 주면 열이 0 으로 접힌다. flexbox 와 여러 줄은 참고 링크로.](/svg/table_cell_ellipsis.svg)

```haskell
-- 말줄임은 맥락마다 다르다
data Context = TableCell | Flex | Multiline    -- Flex · Multiline 은 참고 링크로

-- 표 셀: overflow 셋은 잘라 낼 "경계" 가 있어야 먹는다
ellipsis :: Table -> Cell -> Bool
ellipsis t c = overflowTrio c && bounded
  where bounded = hasWidth t && (layout t == Fixed || maxWidth c == Just 0)
  -- 자동 레이아웃의 셀은 내용만큼 늘어난다 → 경계가 없다
  -- Fixed: 열 너비를 표·col 너비로만 정한다 · maxWidth 0: CSS 2.1 미정의, 브라우저 관행
  -- 표 width 없이 maxWidth 0 만 주면 열이 0 으로 접힌다

-- 셀에 버튼·배지가 같이 있으면 td { max-width: 0 } > div(flex, overflow hidden) > span 에 셋
-- TanStack Table: <colgroup> 에 header.getSize() 를 col 너비로, table-layout: fixed
```
