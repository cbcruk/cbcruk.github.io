![npm link 는 패키지 폴더를 symlink 해서 node_modules 해석·중복 React 같은 문제가 생긴다. yalc 는 패키지에서 yalc publish 하면 npm 에 올라갈 파일만 ~/.yalc 전역 저장소에 복사하고, 앱에서 yalc add 하면 그걸 .yalc 로 끌어와 의존성으로 건다. yalc push 는 저장하면서 연결된 모든 앱에 바로 반영한다 — tsup --watch --onSuccess "yalc push" 로 걸어 두면 저장할 때마다 앱이 갱신된다. .yalc 와 yalc.lock 은 gitignore 한다.](/svg/yalc_publish_push.svg)

```haskell
-- 로컬 패키지를 다른 프로젝트에서 바로 — npm link(symlink) 대신 파일 복사
publish = copy (filesToPublish pkg) "~/.yalc"        -- npm 에 올라갈 파일만
add m   = copy ("~/.yalc" </> m) ".yalc" >> link m   -- 앱에서
push    = publish >> mapM_ update linkedApps         -- = publish --push

-- 저장할 때마다 반영: "dev": "tsup src/index.ts --watch --onSuccess 'yalc push'"
-- 정리: yalc remove my-module && npm install
-- .gitignore: .yalc · yalc.lock
```
