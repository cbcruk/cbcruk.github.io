![initial 은 처음 생길 때의 값으로 다시 정할 일이 드물다. default 는 값이 없을 때 대신 쓰는 값으로 교체할 수 있다. base 는 계산·비교의 기준점이다. original 은 바꾸기 전 원래 값을 보존해 되돌리는 데 쓴다.](/svg/variable_prefixes.svg)

```haskell
-- 변수 prefix: 언제 정해지고 무엇에 쓰는가
data Prefix = Initial | Default | Base | Original

role :: Prefix -> String
role Initial  = "처음 생길 때의 값 — 다시 정할 일이 드물다"   -- initialState = { loggedIn: false }
role Default  = "값이 없을 때 대신 — 교체할 수 있다"           -- defaultPageSize = 20
role Base     = "계산·비교의 기준점"                          -- baseUrl, baseSalary
role Original = "바꾸기 전 값 — 보존해서 되돌린다"             -- originalImage = image.clone()
```
