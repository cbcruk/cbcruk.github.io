![.gitignore 는 아직 추적하지 않는 파일에만 적용되고 이미 추적 중인 파일에는 영향이 없다. git rm -rf --cached . 로 작업 트리는 그대로 두고 인덱스에서만 전부 빼낸 뒤 git add . 로 다시 넣으면, 그때 .gitignore 규칙에 걸리는 파일은 빠진다.](/svg/gitignore_tracked_files.svg)

```haskell
-- .gitignore 는 추적하지 않는 파일에만
ignored :: File -> Bool
ignored f = not (tracked f) && matches gitignore f

-- 이미 추적 중이면 인덱스에서 빼고 다시 넣는다 (작업 트리 파일은 그대로)
-- git rm -rf --cached .  →  git add .
```
