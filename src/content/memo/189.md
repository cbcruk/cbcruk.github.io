`.gitignore` 는 이미 추적 중인 파일에 적용되지 않는다 — 인덱스에서 빼고(`--cached`) 다시 add 해야 규칙이 먹는다.[^189-1]

```sh
# .gitignore가 규칙이 적용되지 않을때
git rm -rf --cached .
git add .
```
