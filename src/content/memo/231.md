![Amplify 는 빌드 명령을 appRoot(apps/app)에서 실행한다. 모노레포 의존성은 루트에서 설치해야 하므로 preBuild 에서 cd ../../ 로 루트로 올라가 yarn install 한다. 그다음 build 단계는 루트에 있으니 앱 파일은 AMPLIFY_MONOREPO_APP_ROOT(= appRoot)로 경로를 되짚는다 — 개발 환경이면 .env.development 를 .env.production 으로 복사하고 build:앱 을 돌린다.](/svg/amplify_monorepo_root.svg)

```haskell
-- Amplify 는 appRoot 에서 명령을 돈다. 의존성은 루트에서 설치해야 한다
build :: AppRoot -> Shell ()
build appRoot = do
  cd "../../" >> yarn "install"                                     -- preBuild: 루트로 올라가 설치
  when (env == ".env.development") $
    cp (appRoot </> env) (appRoot </> ".env.production")            -- 루트에 있으니 $AMPLIFY_MONOREPO_APP_ROOT 로 되짚는다
  yarn ("build:" ++ app)
-- appRoot: apps/app — AMPLIFY_MONOREPO_APP_ROOT 와 같은 값이어야 한다
```
