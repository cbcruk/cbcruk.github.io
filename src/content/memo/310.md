![Link 가 있는 Home 과 About 라우트를 MemoryRouter 로 감싼다 — 브라우저 URL 대신 메모리에 히스토리를 둔다. initialEntries 를 / 로 시작해 링크를 클릭하면 About 의 heading 이 About 인지 본다.](/svg/link_memory_router.svg)

```haskell
-- <Link> 테스트: 브라우저 URL 대신 메모리에 히스토리를 두는 MemoryRouter
navigate :: Path -> [Route] -> Html
navigate p routes = maybe notFound element (find ((== p) . path) routes)

routes = [Route "/" (link "/about" "About"), Route "/about" (h1 "About")]

test = do
  render (memoryRouter ["/"] routes)        -- initialEntries
  click (getByRole "link")
  getByRole "heading" `shouldHaveText` "About"
```
