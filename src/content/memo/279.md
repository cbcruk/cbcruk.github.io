![popover 속성은 auto·hint·manual 중 하나고, 버튼의 popovertarget 이 가리키는 popover 를 popovertargetaction 의 hide·show·toggle 로 연다. 상태는 CSS 로 드러난다 — 열려 있으면 :popover-open, 배경은 ::backdrop. 스크립트로는 showPopover·hidePopover·togglePopover 를 부르고, 바뀌기 전 beforetoggle, 바뀐 뒤 toggle 이벤트가 온다.](/svg/popover_api_shape.svg)

```haskell
-- Popover API 를 컴포넌트 모양으로 읽는다
data Mode   = Auto | Hint | Manual                 -- popover 속성
data Action = Hide | Show | Toggle                 -- popovertargetaction (버튼의 popovertarget 이 대상)

data Popover = Popover { mode :: Mode, open :: Bool }   -- open ↔ CSS :popover-open, 배경 ::backdrop

act :: Action -> Popover -> Popover               -- hidePopover · showPopover · togglePopover
act Hide   p = p { open = False }
act Show   p = p { open = True }
act Toggle p = p { open = not (open p) }
-- 이벤트: beforetoggle (바뀌기 전) → toggle (바뀐 뒤)
```
