![A4(595 × 842 포인트) 빈 PDF 가 필요할 때. skia-canvas 는 그 크기로 캔버스를 만들고 아무것도 그리지 않은 채 toBuffer("pdf") 로 내보낸다 — 형식은 캔버스를 만들 때가 아니라 내보낼 때 정한다(createCanvas(w, h, "pdf") 는 node-canvas API 다). 명령줄이면 Ghostscript 의 pdfwrite 로 빈 페이지 하나를 찍거나, ImageMagick 으로 흰 A4 를 PDF 로 바꾼다.](/svg/empty_pdf_tools.svg)

```haskell
-- A4(595 × 842 pt) 빈 PDF
emptyPdf :: IO Buffer
emptyPdf = toBuffer Pdf (newCanvas 595 842)   -- skia-canvas: 아무것도 안 그리고 내보낸다
-- 형식은 캔버스가 아니라 내보낼 때 정한다 — createCanvas(w, h, 'pdf') 는 node-canvas API

-- 명령줄
-- gs -q -dNOPAUSE -dBATCH -sDEVICE=pdfwrite -sOutputFile=empty.pdf -c "<< /PageSize [595 842] >> setpagedevice showpage"
-- convert xc:white -page A4 empty.pdf
```
