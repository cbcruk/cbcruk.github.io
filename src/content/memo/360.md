![createCancelableFetch 는 AbortController 하나를 만들어 run 과 cancel 을 돌려준다. run 은 그 signal 을 넘겨 fetch 하고, 응답이 ok 가 아니면 HTTP 에러를 던지고, 아니면 JSON 을 돌려준다. cancel 은 abort() 를 부르고, 그러면 진행 중인 fetch 가 AbortError 로 reject 된다 — run 을 받은 쪽의 catch 로 간다.](/svg/cancelable_fetch.svg)

```haskell
-- 취소 가능한 fetch: run 과 cancel 을 한 쌍으로 돌려준다
createCancelableFetch :: Url -> Options -> (IO Json, IO ())
createCancelableFetch url opts = (run, cancel)
  where
    ctrl   = newAbortController
    run    = do r <- fetch url opts { signal = signal ctrl }
                unless (ok r) (throw ("HTTP error! status: " ++ show (status r)))
                json r
    cancel = abort ctrl     -- 진행 중인 fetch 가 AbortError 로 reject 된다
```
