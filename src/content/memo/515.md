![vi.mocked(useSize) 는 타입을 붙여 받은 것을 그대로 돌려줄 뿐이라, 모킹하지 않은 원래 함수에 mockImplementation 을 부르면 undefined 다. vi.hoisted 로 vi.fn() 을 먼저 만들고 vi.mock 이 그걸 모듈 자리에 넣어야, beforeEach 에서 mockImplementation 으로 너비 100 을 돌려줄 수 있다. DOM 측정값(scrollWidth 등)은 Object.defineProperty 로 getter 를 바꾸고 뒤에서 복원한다. 측정이 복잡하면 Playwright·Cypress 로 넘긴다.](/svg/vitest_mocked_vs_hoisted.svg)

```haskell
-- vi.mocked 는 타입만 붙인다 — 구현은 없다
mocked :: a -> Mocked a
mocked = unsafeCoerce                    -- "Just returns the object that was passed"
(mocked useSize).mockImplementation      -- undefined: 원래 함수는 mock 이 아니다

-- 구현은 vi.hoisted 로 먼저 만들어 vi.mock 에 넘긴다
mockUseSize = hoisted fn
mock "ahooks" { useSize = mockUseSize }
beforeEach (mockImplementation mockUseSize (const { width = 100, height = 20 }))

-- DOM 측정값은 getter 를 바꾸고 뒤에서 복원
beforeEach (defineProperty htmlElementPrototype "scrollWidth" { configurable = True, get = 150 })
-- 측정이 복잡하면 Playwright·Cypress 통합 테스트로
```
