![toHaveBeenCalledWith 나 toEqual 의 기대값 자리에 expect.objectContaining 을 넣으면 적은 속성만 맞으면 통과하고 나머지는 무시한다. 그 안의 속성 자리에 expect.arrayContaining 을 넣으면 배열이 적은 원소를 포함하기만 하면 된다. 반대로 배열 안의 객체를 부분 매칭하려면 arrayContaining 안에 objectContaining 을 넣는다.](/svg/jest_partial_match.svg)

```haskell
-- 기대값 자리에 넣는 부분 매처 — 중첩된다
objectContaining :: Map Key Matcher -> Matcher   -- 적은 속성만 맞으면, 나머지는 무시
objectContaining m v = all (\(k, p) -> p (v ! k)) (toList m)
arrayContaining :: [Matcher] -> Matcher          -- 적은 원소를 포함하기만 하면
arrayContaining ps xs = all (\p -> any p xs) ps

-- 호출 인자
toHaveBeenCalledWith mock (objectContaining { name = eq "Alice", tags = arrayContaining [eq "designer"] })
-- 배열 안 객체
toEqual received (arrayContaining [objectContaining { name = eq "Alice" }, objectContaining { id = eq 2 }])
-- 쓰는 자리: toEqual · toHaveBeenCalledWith 의 값, objectContaining · toMatchObject 의 속성
```
