![서버와 프론트가 한 프로젝트인 환경에서, 이미 8080 에 떠 있는 서버 앞에 browser-sync 를 8081 로 프록시로 둔다. /resources 경로만 소스 폴더에서 직접 서빙하고 그 폴더를 감시해, CSS·이미지는 주입하고 나머지는 브라우저를 새로 고친다.](/svg/browser_sync_proxy.svg)

```haskell
-- 서버/프론트 구분이 없는 환경에서 옛날에 쓰던 세팅
-- 이미 떠 있는 서버 앞에 프록시를 두고 정적 파일만 직접 감시한다
route :: Path -> Source
route p | "/resources" `isPrefixOf` p = Dir "src/main/webapp/resources"   -- serveStatic
        | otherwise                   = Proxy "http://localhost:8080"     -- proxy

-- port 8081 · files 'src/main/webapp/resources/**/*' 가 바뀌면 CSS·이미지는 주입, 나머지는 새로 고침
```
