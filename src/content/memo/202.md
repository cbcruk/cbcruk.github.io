![다른 저장소를 remote 로 추가하고 fetch 한 뒤 그 브랜치를 merge 한다. 두 히스토리는 공통 조상이 없어서 git merge 가 기본으로 거부하므로, --allow-unrelated-histories 로 그 안전장치를 끈다. 양쪽 커밋 히스토리가 모두 남는다.](/svg/git_merge_unrelated.svg)

```haskell
-- 저장소 둘을 히스토리째 합친다
merge :: Flags -> Branch -> Branch -> Either Refused Branch
merge flags a b
  | isJust (commonAncestor a b)           = Right (mergeCommit a b)
  | AllowUnrelatedHistories `elem` flags  = Right (mergeCommit a b)   -- 안전장치를 끈다
  | otherwise                             = Left Refused

-- git remote add {alias} {url} && git fetch {alias}
-- git merge --allow-unrelated-histories {alias}/{branch}
```
