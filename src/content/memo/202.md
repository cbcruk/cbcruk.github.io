`git merge` 는 공통 조상이 없는 히스토리를 기본으로 거부한다 — `--allow-unrelated-histories` 가 그 안전장치를 끈다.[^202-1]

```sh
git remote add {alias} {url}
git fetch {alias}
git merge --allow-unrelated-histories {alias}/{branch}
```
