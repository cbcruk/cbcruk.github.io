![구글 스프레드시트에서 A열의 중복 값에 서식을 주려면 서식 → 조건부 서식 → 맞춤 수식에 =COUNTIF(A:A, A1)>1 을 넣는다. 수식은 범위의 첫 행(A1) 기준으로 쓰고, 시트가 행마다 A1 을 A2, A3 … 으로 옮겨 가며 평가한다. 그 값이 A열에 두 번 이상 나오면 참이라 칠해진다.](/svg/sheets_duplicate_highlight.svg)

```haskell
-- 구글 시트에서 중복 값에 서식: 서식 > 조건부 서식 > 맞춤 수식
-- =COUNTIF(A:A, A1)>1  — 첫 행 기준으로 쓰면 행마다 A1 이 A2, A3 … 으로 미끄러진다
highlight :: [Value] -> Int -> Bool
highlight col row = count (== col !! row) col > 1

map (highlight ["사과", "배", "사과", "감", "배"]) [0..4] == [True, True, True, False, True]
```
