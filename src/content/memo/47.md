![isLoading·isError 같은 불리언을 따로 두면 동시에 참일 수 없는 조합이 생긴다. 상태를 idle(아직 아무 일도 없음)·loading(진행 중)·success(성공)·failure(오류) 중 하나로 두면, 버튼 비활성화 같은 UI 는 그 상태에서 나온다.](/svg/status_four_states.svg)

```haskell
-- 불리언 여럿 대신 상태 하나
data Status = Idle      -- 아직 아무 일도 일어나지 않았다
            | Loading   -- 진행 중
            | Success   -- 성공
            | Failure   -- 오류

disabled :: Status -> Bool
disabled s = s == Loading      -- 버튼 비활성화는 상태에서 나온다
```
