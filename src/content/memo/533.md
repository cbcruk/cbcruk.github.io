![null 일 수 있는 단계를 잇는다: 스크롤 요소 → 그 안의 #id 요소 → 첫 사각형 → scrollLeft 를 그 left 로. 어느 단계든 null 이 나오면 뒤 단계는 부르지 않고 null 로 끝난다. Maybe 의 map 으로 쓰면 체인 하나, generator 로 쓰면 단계마다 if (!x) return 으로 일찍 빠져나간다 — 같은 모양이다.](/svg/maybe_null_chain.svg)

```haskell
-- null 일 수 있는 단계를 체크 없이 잇는다
fmap :: (a -> b) -> Maybe a -> Maybe b
fmap f (Just x) = ofNullable (f x)   -- 결과가 null 이면 Nothing 으로
fmap _ Nothing  = Nothing            -- 뒤 단계는 부르지 않는다

scrollTo id = ofNullable scrollElement
  >>= querySelector ("#" ++ id)
  >>= (listToMaybe . getClientRects)
  <&> \rect -> root.scrollLeft := left rect

-- generator 로 쓰면 같은 모양의 early return
handleScroll id = do
  root   <- scrollElement   -- if (!root) return
  target <- querySelector ("#" ++ id) root   -- if (!target) return
  yield (maybe 0 left (listToMaybe (getClientRects target)))
```
