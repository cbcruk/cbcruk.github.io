![같은 조건부 렌더링을 두 자리에서 할 수 있다. A 는 Item 에 isPacked 를 넘기고 Item 이 안에서 null 을 돌려준다 — 부모 JSX 만 보면 Item 이 그려질 것 같아 디버깅이 어렵다. B 는 부모가 isPacked ? <Item/> : null 로 넣을지 말지를 정한다. react.dev 도 B 가 더 흔하다고 한다. If·Then·Else 컴포넌트는 children 을 type 으로 골라 B 를 선언적으로 쓰는 시도다.](/svg/conditional_render_parent.svg)

```haskell
-- 조건부 렌더링을 어디서 하나
renderA = item { isPacked = True, name = "Space suit" }   -- Item 안에서 null — 부모만 보면 그려질 것 같다
renderB = if isPacked then Just (item { name = "Space suit" }) else Nothing   -- 부모가 고른다 (react.dev: 더 흔하다)
-- 디버깅에 데이고 나서 B 쪽으로 생각이 바뀌었다

-- B 를 선언적으로: If · Then · Else — children 을 type 으로 골라
ifThenElse :: Bool -> [Element] -> Maybe Element
ifThenElse cond cs = find ((== (if cond then Then else Else)) . type') (filter isValidElement cs)
```
