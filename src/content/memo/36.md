![커스텀 훅이 reducer 를 인자로 받으면 상태 갱신 규칙을 호출하는 쪽으로 넘길 수 있다. 넘긴 reducer 가 돌려준 값이 곧 다음 state 이므로, 호출자는 기본 reducer 를 불러 그 결과를 돌려주면 기본 동작을 유지하면서 그 앞뒤에 끼어들 수 있다.](/svg/state_reducer_pattern.svg)

```haskell
-- 훅이 reducer 를 받으면 갱신 규칙을 호출자에게 넘길 수 있다
useToggle :: Maybe Reducer -> (State, Dispatch)
useToggle r = useReducer (fromMaybe toggleReducer r) initial

-- 넘긴 reducer 의 반환값이 다음 state — 기본 reducer 를 불러 돌려주면 기본 동작 유지
custom :: Reducer
custom state action = trace (show (state, action)) (toggleReducer state action)
```
