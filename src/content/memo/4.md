![캔버스로 동영상 프레임을 캡처하거나, 텍스트를 서버에 보내 음성 파일을 응답으로 받으면 둘 다 Blob 이 된다. URL.createObjectURL(blob) 로 그 Blob 을 가리키는 blob: URL 을 만들어 img 의 src 나 audio 의 src 에 넣으면 바로 보이고 들린다. axios 로 받을 땐 responseType 을 blob 으로 준다.](/svg/blob_object_url.svg)

```haskell
-- 캔버스 프레임 · 서버가 준 음성 파일 → 둘 다 Blob → URL 로 바꿔 태그에 꽂는다
objectUrl :: Blob -> IO Url                      -- URL.createObjectURL(blob) → "blob:…"

show :: Blob -> IO ()
show b = objectUrl b >>= \u -> setSrc img u      -- 음성이면 <audio>
-- axios: { responseType: 'blob' }
```
