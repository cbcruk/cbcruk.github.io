![웹 페이지에서 chrome-extension://<id>/icon-128.png 를 img 로 불러 보고, 로드되면 설치된 것, 에러면 없거나 막힌 것으로 본다. 웹 페이지가 읽을 수 있는 확장 리소스는 manifest 의 web_accessible_resources 에 선언된 것뿐이라, 그 확장이 아이콘을 공개해 두었을 때만 이 방법이 통한다 — 기본값은 지문 채취를 막으려고 아무것도 공개하지 않는다.](/svg/extension_installed_probe.svg)

```haskell
-- 확장 리소스를 이미지로 불러 본다
isInstalled :: ExtensionId -> IO Bool
isInstalled ext = loads ("chrome-extension://" ++ ext ++ "/icon-128.png")   -- onload → True · onerror → False

-- 웹 페이지가 읽을 수 있는 건 web_accessible_resources 에 선언된 것뿐
-- 기본은 아무것도 공개하지 않는다 (지문 채취 방지) → onerror 는 "없음" 과 "비공개" 를 못 가른다
-- 설치 경로(macOS): ~/Library/Application Support/Google/Chrome/Default/Extensions
```
