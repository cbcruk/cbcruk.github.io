![같은 이벤트가 연달아 들어올 때, throttle 은 정해진 간격마다 많아야 한 번만 실행해 속도를 제한한다 — 스크롤 위치를 계속 따라갈 때. debounce 는 호출이 멈추고 정해진 시간이 지나야 마지막 것 한 번만 실행한다 — 검색 입력이 끝났을 때나 창 크기 조정이 끝났을 때.](/svg/throttle_vs_debounce.svg)

```haskell
-- 연달아 들어오는 이벤트를 줄이는 두 방식
throttle :: Ms -> [Event] -> [Event]      -- 간격마다 많아야 한 번: 속도를 제한한다 (스크롤)
throttle gap (e : es) = e : throttle gap (dropWhile ((< time e + gap) . time) es)
throttle _   []       = []

debounce :: Ms -> [Event] -> [Event]      -- 호출이 gap 동안 멈춰야 그 마지막 하나 (검색 입력, 리사이즈 끝)
debounce gap es = [e | (e, next) <- zip es (map Just (drop 1 es) ++ [Nothing])
                     , maybe True ((>= time e + gap) . time) next]
```
