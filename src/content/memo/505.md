![테스트 파일 하나마다 순서는 setupFiles → 테스트 프레임워크 설치 → setupFilesAfterEnv → 테스트 코드다. setupFiles 시점엔 jest 객체는 있지만 expect·beforeEach 는 아직 없어 환경 변수·폴리필에 쓴다. setupFilesAfterEnv 는 그 뒤라 jest-dom matcher, jest.setTimeout, 전역 beforeEach 를 둔다. 둘 다 테스트 코드보다 먼저 돌아서 어느 쪽에서 넣은 process.env 든 테스트가 import 하는 모듈에 보인다 — 나누는 건 용도 때문이다.](/svg/jest_setup_order.svg)

```haskell
-- 테스트 파일마다 이 순서
run = setupFiles >> installFramework >> setupFilesAfterEnv >> tests

setupFiles         = process.env.API_URL := "http://test-api.example.com"   -- 환경 변수·폴리필
  -- jest 객체는 있다. expect·beforeEach 는 아직 없다
setupFilesAfterEnv = import "@testing-library/jest-dom"                      -- matcher·jest.setTimeout
                   >> beforeEach jest.clearAllMocks                           -- 전역 훅

-- 둘 다 tests 보다 먼저라 어느 쪽에서 넣은 env 든 테스트가 import 하는 모듈에 보인다
-- env 를 setupFiles 에 두는 건 용도 구분이다
```
