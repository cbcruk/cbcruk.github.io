![이번 달 1일과 말일 사이의 각 주 시작일을 eachWeekOfInterval 로 구하고, 주마다 그 시작일부터 6일 뒤까지를 eachDayOfInterval 로 펼치면 주 × 7 의 날짜 행렬이 된다. 첫 주와 마지막 주에는 앞뒤 달의 날짜도 들어온다.](/svg/calendar_matrix.svg)

```haskell
-- 달력 행렬: 이번 달의 각 주 시작일 → 주마다 7일
matrix :: Day -> [[Day]]
matrix today = [ [w `addDays` i | i <- [0 .. 6]]       -- eachDayOfInterval { start = w, end = w + 6 }
               | w <- eachWeekOfInterval (startOfMonth today) (endOfMonth today) ]
-- 첫 주·마지막 주에는 앞뒤 달 날짜가 섞인다
```
