![Mounting 에서 이메일 입력 대기나 코드 입력 대기로 간다. 이메일을 제출하면 SubmittingEmail 이 되고, 성공하면 코드 입력 대기로, 실패하면 다시 이메일 입력 대기로 돌아간다. 코드를 제출하면 SubmittingCode 가 되고, 성공하면 Success, 실패하면 코드 입력 대기로 돌아간다. 불리언 여러 개로 짜도 상태 머신은 생긴다 — 암시적이냐 명시적이냐의 차이다.](/svg/email_login_states.svg)

```haskell
-- 불리언 수프도 상태 머신이다 — 암시적이냐 명시적이냐의 차이
data State = Mounting | AwaitingEmail | SubmittingEmail | AwaitingCode | SubmittingCode | Success

step :: State -> Event -> State
step Mounting        HasEmail   = AwaitingEmail
step Mounting        HasPending = AwaitingCode
step AwaitingEmail   Submit     = SubmittingEmail
step SubmittingEmail Ok         = AwaitingCode
step SubmittingEmail Fail       = AwaitingEmail
step AwaitingCode    Submit     = SubmittingCode
step SubmittingCode  Ok         = Success
step SubmittingCode  Fail       = AwaitingCode
step s               _          = s              -- 그 밖의 조합은 일어나지 않는다
```
