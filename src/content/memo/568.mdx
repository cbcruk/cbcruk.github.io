![목록 90개에서 매번 무작위로 하나를 뽑을 때, i 번째 새 항목을 만나기까지의 평균 대기는 90/(90-i+1) 번이다. 앞쪽 절반은 거의 매번 새것이 나오지만 끝으로 갈수록 대기가 급격히 길어지고, 마지막 한 개는 평균 90번을 기다린다 — 섞어서 한 바퀴 돌면 90개 전부를 보는 횟수다. 다 합치면 평균 457번으로, 섞어 도는 90번의 약 5배다.](/svg/coupon_collector_tail.svg)

```haskell
-- 목록 n 개에서 매번 무작위로 하나를 뽑는다 (작업 중 문구를 바꿔 띄우는 스피너 같은 것)
-- n 개를 다 보려면 몇 번? — 섞어서 한 바퀴 돌면 n 번이지만, 매번 전체에서 다시 뽑는다

-- i 번째 새 항목: 남은 n - i + 1 개 중 하나가 걸릴 때까지
wait :: Double -> Double -> Double
wait n i = n / (n - i + 1)

expected :: Double -> Double
expected n = sum [wait n i | i <- [1..n]]   -- = n × H_n (쿠폰 수집가)

expected 90 ≈ 457   -- 5배. 1초에 하나면 7분 반
wait 90 90  = 90    -- 꼬리: 마지막 한 개에만 섞어 돌 때의 전부만큼
```
