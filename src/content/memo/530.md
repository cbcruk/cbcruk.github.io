![점이 폴리곤 안에 있는지 turf.booleanPointInPolygon 으로 본다. GeoJSON 좌표는 [경도, 위도] 순서다 — 위도부터 쓰면 다른 곳을 가리킨다. 폴리곤의 고리는 마지막 점이 첫 점과 같아야 닫힌다. 예: 사각형 네 꼭짓점 + 첫 점을 다시 넣은 다섯 점, 그 안의 [-73.978, 40.766] 은 true.](/svg/turf_point_in_polygon.svg)

```haskell
-- 좌표가 영역 안에 있는가 — turf.js (npm install @turf/turf)
type Position = (Lng, Lat)          -- 경도가 먼저
type Ring     = [Position]          -- last ring == head ring 이어야 닫힌다

booleanPointInPolygon :: Point -> Polygon -> Bool

square = polygon [[ (-73.981, 40.768), (-73.981, 40.764)
                  , (-73.975, 40.764), (-73.975, 40.768)
                  , (-73.981, 40.768) ]]          -- 닫기
booleanPointInPolygon (point (-73.978, 40.766)) square == True
```
