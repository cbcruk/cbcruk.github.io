![new File([""], "default.csv", \{ type: "text/csv" \}) 는 크기 0 인 파일이다. File 은 Blob 이라 FormData.append 가 문자열이 아니라 파일 필드로 받고, 파일명은 File 의 이름(default.csv)이 그대로 간다. MIME 타입을 지정해 서버가 기대하는 형식의 빈 파일을 보낼 수 있어서, 파일 필드가 필수인 API 를 테스트하거나 기본값을 채울 때 쓴다.](/svg/empty_file_formdata.svg)

```haskell
-- 빈 파일을 FormData 에 첨부해 보낸다
emptyCsv = File [""] "default.csv" { type' = "text/csv" }   -- size == 0
emptyPng = File [""] "default.png" { type' = "image/png" }

append :: Name -> Either String Blob -> FormData -> FormData
-- File 은 Blob 이라 파일 필드로 들어가고, 파일명은 File 의 이름이 그대로 간다
form = append "product_coupons" (Right emptyCsv)
     . append "product_imgs"    (Right emptyPng) $ formData
-- 파일 필드가 필수인 API 테스트 · 기본값 채우기에
```
