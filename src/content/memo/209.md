![zx 의 $ 템플릿은 ${} 로 넣은 값을 자동으로 이스케이프하고 따옴표로 감싼다. 그래서 --paths ${paths} 에 /* 를 넣으면 셸 글롭으로 펼쳐지지 않고 그대로 전달된다. 따옴표를 직접 붙여 "/*" 로 넣으면 따옴표까지 경로의 일부가 된다.](/svg/zx_auto_quote.svg)

```haskell
-- CloudFront 캐시 무효화를 zx 로
createInvalidation :: DistributionId -> Path -> IO Result
createInvalidation dist paths =
  sh ["aws", "cloudfront", "create-invalidation", "--distribution-id", quote dist, "--paths", quote paths]
  -- zx 의 $: ${} 로 넣은 값은 알아서 quote — 직접 "/*" 를 넣으면 따옴표까지 경로가 된다

createInvalidation dist "/*"   -- 배포 전체
```
