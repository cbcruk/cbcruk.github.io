![부모 폭 300 에 자식 폭 500 을 넣으면 scrollWidth 500 이 clientWidth 300 보다 커서 가로 스크롤이 생긴다 — 이걸 단언하는 테스트는 실제 브라우저(Vitest browser mode·Playwright)에서만 통과한다. jsdom 은 레이아웃을 하지 않아 scrollWidth·clientWidth·getBoundingClientRect 가 전부 0 이라 0 > 0 이 false 다. jsdom 에서 돌려야 하면 Object.defineProperty 로 두 값을 모킹한다(515).](/svg/overflow_test_layout.svg)

```haskell
-- 넘치면 스크롤 — 레이아웃이 계산돼야 의미가 있다
horizontal el = scrollWidth el  > clientWidth el
vertical   el = scrollHeight el > clientHeight el

-- 실제 브라우저(Vitest browser mode·Playwright)에서
horizontal (render parent 300 child 500) == True
horizontal (render parent 400 child 300) == False   -- rerender 로 child 600 → True

-- jsdom 은 레이아웃을 하지 않는다: 레이아웃 값이 전부 0
inJsdom = horizontal el == (0 > 0) == False           -- True 를 기대하는 단언이 둘 다 실패
-- jsdom 에서 돌려야 하면 Object.defineProperty 로 scrollWidth·clientWidth 를 모킹한다 (515)
-- getBoundingClientRect() 도 0
```
