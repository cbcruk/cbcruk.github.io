httpOnly, secure 플래그 쿠키값이 필요한 경우 브라우저 쿠키 저장소에서 꺼낸다. `HttpOnly` 는 페이지의 JS(`document.cookie`)에서만 가려질 뿐 브라우저 쿠키 저장소에는 있다.[^91-httponly] Puppeteer 25 기준 `browser.cookies()` 가 그 저장소를 읽는다.[^91-cookies]
```js
const cookies = await browser.cookies() // HttpOnly 쿠키도 httpOnly: true 로 들어 있다
```

로컬에 해당 쿠키정보를 임시로 저장해서 재활용하고 만료 시 갱신하는 방법을 사용.
```js
fs.writeFileSync('cookies.json', JSON.stringify(cookies))

await browser.setCookie(...JSON.parse(fs.readFileSync('cookies.json', 'utf8')))
```

예전 방식(CDP `Network.getAllCookies`, `page.setCookie`)은 둘 다 폐기됐다.[^91-deprecated]
