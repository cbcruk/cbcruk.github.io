![HttpOnly 는 페이지의 JS(document.cookie)에서만 가려질 뿐 브라우저 쿠키 저장소에는 있다. Puppeteer 의 browser.cookies() 가 그 저장소를 읽으므로 HttpOnly·Secure 쿠키도 받는다. 받은 쿠키를 파일에 저장해 두고 다음에 browser.setCookie 로 되돌려 쓰다가 만료되면 갱신한다. 예전 방식인 CDP Network.getAllCookies 와 page.setCookie 는 폐기됐다.](/svg/puppeteer_httponly_cookies.svg)

```haskell
-- HttpOnly 는 페이지 JS(document.cookie)에서만 가려진다 — 저장소에는 있다
cookies :: Browser -> IO [Cookie]           -- browser.cookies(): httpOnly: true 도 들어 있다

reuse :: Browser -> IO ()
reuse b = do
  saved <- decode <$> readFile "cookies.json"
  if any expired saved
    then cookies b >>= writeFile "cookies.json" . encode     -- 만료되면 갱신
    else setCookie b saved                                   -- browser.setCookie(...saved)
-- 폐기: CDP Network.getAllCookies · page.setCookie
```
