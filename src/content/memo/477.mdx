![이모지 데이터의 unified 값은 1F468-200D-1F469 처럼 16진수 코드 포인트를 - 로 이은 것이다. - 로 나눠 각각 16진수 정수로 바꾸고 String.fromCodePoint 로 문자를 만든 뒤 이어 붙인다. 0xFFFF 를 넘는 코드 포인트(1F468 등)는 서로게이트 쌍이 필요해서 fromCharCode 로는 안 되고 fromCodePoint 라야 한다.](/svg/emoji_unified_codepoint.svg)

```haskell
-- 이모지 데이터의 unified("1F468-200D-1F469")를 문자로
parseNativeEmoji :: String -> String
parseNativeEmoji = concatMap (fromCodePoint . readHex) . splitOn "-"
-- "-" 로 나눠 코드 포인트를 하나씩 얻고, 16진수를 정수로 바꿔 그 문자를 얻고, 이어 붙여 하나의 문자열로
-- fromCodePoint 는 0xFFFF 를 넘는 코드 포인트도 받아 서로게이트 쌍을 만든다 — fromCharCode 는 못 한다
```
