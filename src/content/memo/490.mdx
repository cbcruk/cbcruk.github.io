![탭 전환·최소화·앱 전환으로 보임 상태가 바뀌면 document 에 visibilitychange 가 오고 visibilityState 가 visible 또는 hidden 이 된다. 그런데 시스템이 잠들었다 깨면 이 이벤트가 안 올 때가 있어, hidden 상태일 때만 mouseenter·keydown 을 걸어 두고 입력이 오면 visible 로 되돌린다. React 훅은 상태가 실제로 바뀔 때만 set 한다.](/svg/visibility_state_wake.svg)

```haskell
-- 탭 전환·최소화·앱 전환으로 보임 상태가 바뀌면 document 에 visibilitychange
visible :: Event -> Visibility -> Visibility
visible VisibilityChange _      = visibilityState document   -- "visible" | "hidden"
visible (Input _)        Hidden = Visible                    -- 잠들었다 깨면 visibilitychange 가 안 올 때가 있다
visible _                v      = v                          -- 그래서 hidden 일 때만 mouseenter·keydown 을 건다

-- React: 실제로 바뀔 때만 set
onChange = do
  v <- (/= Hidden) <$> visibilityState document
  when (v /= isVisible) (setIsVisible v)
```
