`visibilitychange` 는 탭 전환·최소화·앱 전환처럼 보임 상태가 바뀔 때 document 에서 발생한다.[^490-1]

```ts
const isVisible = document.visibilityState === 'visible'
const isHidden = document.visibilityState === 'hidden'

document.addEventListener('visibilitychange', onChange)
```

---

시스템이 잠들면 `visibilitychange` 가 안 올 때가 있다 — hidden 상태일 때만 입력으로 복귀를 잡는다.[^490-2]

```ts
if (document.visibilityState === 'hidden') {
  document.addEventListener('mouseenter', setVisible)
  document.addEventListener('keydown', setVisible)
}
```

---

```ts
const [isVisible, setIsVisible] = useState(true)

useEffect(() => {
  const onChange = () => {
    const newState = document.visibilityState !== 'hidden'

    if (newState !== isVisible) {
      setIsVisible(newState)
    }
  }

  // addEventListener

  return () => {
    // removeEventListener
  }
}, [isVisible])
```
