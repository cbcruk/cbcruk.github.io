![모달은 닫기 전까지 상호작용을 막는다. 무엇을 막느냐로 셋이다: 시스템 모달은 시스템 전체, 애플리케이션 모달은 그 프로그램, 문서 모달은 부모 창 하나(macOS 시트). 모델리스는 아무것도 막지 않아 툴바처럼 열어 둔 채 작업한다. 모달은 작업 흐름을 끊으므로 계속하는 데 꼭 필요한 정보가 아니면 모델리스를 쓴다.](/svg/dialog_modality.svg)

```haskell
-- 대화 상자는 무엇을 막느냐로 갈린다
data Scope  = System | Application | Document   -- Document: 부모 창만 (macOS 시트)
data Dialog = Modal Scope                       -- 닫기 전까지 그 범위의 상호작용을 막는다
            | Modeless                          -- 막지 않는다 (툴바)

choose :: Essential -> Dialog
choose True  = Modal Application
choose False = Modeless          -- 모달은 흐름을 끊는다: 꼭 필요한 정보가 아니면 모델리스

```
