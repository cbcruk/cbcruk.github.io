- [단순 요청 조건](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS#simple_requests)을 벗어나면 브라우저가 본 요청 전에 자동으로 보낸다[^53-1]
- OPTIONS 메서드로 요청
- cloudfront에 OPTIONS 메서드 설정이 안되어 있다면 실패[^53-2]

[^53-1]: [Preflighted requests | MDN](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS#preflighted_requests): *"Unlike simple requests, for "preflighted" requests the browser first sends an HTTP request using the OPTIONS method to the resource on the other origin, in order to determine if the actual request is safe to send."*
