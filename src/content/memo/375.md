![document.activeElement 는 지금 포커스를 가진 요소다. 입력창이면 그 값을 읽을 수 있다. 모달을 열 때는 닫기 버튼에 focus() 를 불러 포커스를 모달 안으로 옮긴다 — 그러면 activeElement 가 닫기 버튼이 된다.](/svg/active_element_focus.svg)

```haskell
-- 지금 포커스된 요소
activeElement :: Document -> Element

readInput = do
  el <- activeElement document
  when (tagName el == "INPUT") (print (value el))

-- 모달이 열리면 닫기 버튼으로 포커스를 옮긴다 — activeElement 가 바뀐다
openModal = focus =<< querySelector ".modal .close-button"
```
