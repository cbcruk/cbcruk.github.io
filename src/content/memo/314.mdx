![new Date() 나 Math.random() 을 컴포넌트 안에서 바로 부르면 테스트마다 결과가 달라진다. 기본 매개변수로 받으면 인자를 안 넘긴 프로덕션에서는 호출할 때마다 new Date() 가 평가되고, 테스트에서는 new Date(2023, 0, 1) 이나 () => 0.5 를 넘겨 결과를 고정한다. 날짜는 toLocaleDateString("sv-SE") 로 로컬 YYYY-MM-DD 를 만든다 — toISOString 은 UTC 라 KST 오전 9시 전엔 하루 밀린다.](/svg/inject_impure_defaults.svg)

```haskell
-- 비순수 값(Date·Math.random)은 기본 매개변수로 받는다 — 기본값은 호출할 때마다 평가된다
dateInput :: Maybe Date -> IO Html
dateInput now = do
  d <- maybe newDate pure now                   -- { now = new Date() }
  pure (input "date" (localYmd d))              -- toLocaleDateString('sv-SE'); toISOString 은 UTC 라 하루 밀린다

random :: IO Double -> IO Html
random randomizer = div . show <$> randomizer   -- { randomizer = Math.random }

-- 테스트: 값을 넘겨 고정한다
-- dateInput (Just (Date 2023 0 1)) → "2023-01-01" · random (pure 0.5) → "0.5"
```
