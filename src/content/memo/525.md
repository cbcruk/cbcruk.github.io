![gulp.src 가 어떤 파일을 잡는지 세 군데서 볼 수 있다. 파이프 전에 glob 패턴만 globSync 로 찍어 보고, 파이프 안에서 gulp-debug 로 파일 이름과 개수를 찍거나, through2 로 파일 객체를 받아 원하는 속성을 찍고 그대로 넘긴다. NODE_ENV=debug 일 때만 gulp-if 로 debug 를 끼운다. gulp-debug 5 는 ESM 전용이라 gulpfile.mjs 로 쓴다.](/svg/gulp_src_debug.svg)

```haskell
-- gulp.src 가 어떤 파일을 잡는지 본다 — gulp 5 · gulp-debug 5(ESM 전용, gulpfile.mjs) · glob 14
src :: Glob -> Stream File

before   = print (globSync "src/**/*.js")                         -- 1 파이프 전에 패턴만
named    = src "src/**/*.js" |> debug { title = "Files:" }         -- 2 이름과 개수
detailed = src "src/**/*.js" |> through2 (\f -> print (relative f) >> pure f)   -- 3 파일 객체를 받아 그대로 넘긴다

-- 조건부: NODE_ENV=debug gulp build
build = src "src/**/*.js" |> gulpif (env "NODE_ENV" == "debug") debug
```
