![컴포넌트를 JSX 로 쓸 때 cannot be used as a JSX component 가 나면 대개 @types/react·@types/react-dom 참조가 어긋난 것이다. 의존성 트리에 서로 다른 버전의 @types/react 가 두 벌 깔리면 컴포넌트가 돌려주는 ReactElement 와 JSX 가 기대하는 타입이 서로 다른 선언이 되어 맞지 않는다.](/svg/jsx_component_types_mismatch.svg)

```haskell
-- "cannot be used as a JSX component": @types/react 참조가 어긋났다
usableAsJsx :: Component -> Bool
usableAsJsx c = returnType c == jsxElement   -- 두 벌의 @types/react 면 이름만 같은 다른 선언

-- 해결: 의존성 트리에서 @types/react · @types/react-dom 을 한 버전으로 (resolutions / overrides)
```
