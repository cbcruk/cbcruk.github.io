![PNG 마다 sharp 의 trim 으로 가장자리 여백을 잘라 낸 뒤, 잘린 이미지의 크기를 다시 읽어 가로·세로를 절반으로 resize 하고 .half.png 로 저장한다. 특정 영역만 잘라 내려면 extract 에 left·top 오프셋과 width·height 를 준다.](/svg/sharp_trim_half.svg)

```haskell
-- PNG 마다: 여백을 자르고 절반으로
half :: Image -> Image
half img = resize (round (w / 2), round (h / 2)) t
  where t      = trim img            -- 가장자리 여백 제거
        (w, h) = size t              -- 잘린 뒤 크기를 다시 읽는다

-- crop: extract { left = 50, top = 50, width = 200, height = 400 }
```
