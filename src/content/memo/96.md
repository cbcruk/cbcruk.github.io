![지금 설치된 formula·cask·tap 을 brew bundle dump 로 Brewfile 에 써 두고, 새 기기에서는 그 파일이 있는 곳에서 brew bundle 로 한 번에 설치한다.](/svg/brew_bundle_roundtrip.svg)

```haskell
-- 설치된 것을 파일로 떠 두고, 새 기기에서 그대로 설치한다
dump   :: Machine -> Brewfile          -- brew bundle dump
bundle :: Brewfile -> Machine -> Machine   -- brew bundle

newMac = bundle (dump oldMac) emptyMac
```
