```haskell
-- 스피너가 한 프레임 번쩍하거나, 떴다가 하드컷으로 끊긴다: 깜빡임은 양 끝에서 따로 생긴다
-- 보인 구간 [뜬 시각, 사라진 시각) — DOM 에 붙어 있던 시간이 아니다
shown :: Delay -> MinShow -> Response -> Interval
shown delay minShow res
  | res < delay = empty                              -- 앞쪽: CSS animation-delay 가 통째로 건너뛴다
  | otherwise   = (delay, max res (delay + minShow)) -- 뒤쪽: 끝은 응답 시각인데 CSS 는 그걸 모른다
                                                     --       → JS(useMinimumLoading)가 unmount 를 민다
-- 최소 노출은 처음 보인 시각부터 잰다. 요청 시점부터 재면 안 떠도 될 스피너를 붙잡는다
-- @starting-style 은 진입의 출발값만 정한다 — 지연 0 이면 앞쪽을 못 막는다

-- 실측 (Chrome 154, CDP 로 응답을 붙잡고 프로브·스크린샷 trace 로 잼, ms)
--   지연  응답  최소노출   보인 시간
--     0   100    —        133         앞쪽
--   300   100    —          0         억제
--   300   350    —         66         뒤쪽: 페이드가 끝나기 전에 끊겨 한 번도 진해지지 못한다
--   300   350   500       515         뒤쪽 잡힘
--   300   100   500         0         억제 유지
```
