![FormData 를 만들어 단일 파일 입력의 첫 파일을 single 로, 다중 파일 입력의 파일들은 multiple_0, multiple_1 … 로 append 한 뒤 fetch 의 body 에 그대로 넣어 POST 한다. Content-Type 은 브라우저가 multipart 경계와 함께 정한다.](/svg/formdata_file_upload.svg)

```haskell
-- 파일 업로드: FormData 에 담아 body 로
formData :: File -> [File] -> FormData
formData single multiple =
  ("single", single) : [("multiple_" ++ show i, f) | (i, f) <- zip [0 ..] multiple]
```
