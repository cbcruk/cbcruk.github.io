![Redux 스타일 store 는 상태 하나와 리스너 목록 하나다. dispatch(action) 은 reducer(지금 상태, action) 으로 새 상태를 만들어 갈아 끼우고, 리스너 전부에게 새 상태를 알린 뒤 action 을 돌려준다. subscribe 는 리스너를 곧바로 지금 상태로 한 번 부르고 목록에 넣으며, 목록에서 빼는 함수를 돌려준다. getState 는 지금 상태를 읽는다.](/svg/redux_store_dispatch.svg)

```haskell
-- state 는 클로저에 가두고, 바꾸는 길은 dispatch → reducer 하나뿐
createStore :: (s -> a -> s) -> s -> Store s a
dispatch a = do state %= (`reducer` a)
                s <- read state
                mapM_ ($ s) =<< read listeners
                pure a

-- Redux 와 다른 점: 리스너에 state 를 넘기고, 등록 즉시 한 번 부른다
subscribe  l = l =<< read state >> listeners %= (l :) >> pure (listeners %= filter (/= l))
subscribeR l = listeners %= (l :)            -- Redux: 인자 없이 부르고, 리스너가 getState() 로 읽는다

reducer s (Add item) = s { items = items s ++ [item] }
reducer s _          = s

store = createStore reducer { items = [] }
subscribe store (print . items)
dispatch store (Add { body = "hello" })
```
