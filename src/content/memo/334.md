![expireAt 에 Date 를 넣고 { expireAt: 1 } 에 expireAfterSeconds: 0 인 TTL 인덱스를 걸면, 그 시각이 지난 문서를 MongoDB 가 지운다. 지우는 건 60초마다 도는 백그라운드 작업이라 즉시가 아니다. expireAt 이 Date 가 아니면 만료되지 않는다. 세션 만료·캐시·임시 데이터에 쓴다. SQLite 엔 TTL 이 없어 트리거나 외부 스케줄러로 만든다.](/svg/mongodb_ttl_index.svg)

```haskell
-- TTL 인덱스: 시각이 지난 문서를 MongoDB 가 지운다
-- db.collection.createIndex({ expireAt: 1 }, { expireAfterSeconds: 0 })
expired :: Time -> Doc -> Bool
expired now doc = maybe False (<= now) (asDate (expireAt doc))   -- Date 가 아니면 만료되지 않는다

ttlMonitor = forever $ do                  -- 60초 간격 백그라운드 — 즉시 삭제가 아니다
  now <- getTime
  deleteMany (expired now)
  sleep 60
-- 세션 만료 · 캐시 · 임시 데이터. SQLite 는 TTL 이 없어 트리거나 외부 스케줄러로
```
