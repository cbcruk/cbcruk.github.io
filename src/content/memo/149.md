![스토리는 as a(누가) · I want(무엇을) · so that(왜) 로 쓴다. 기능(Feature) 하나에 시나리오 여럿, 시나리오 하나에 단계 여럿이다. Given 은 초기 상태로 보통 과거에 일어난 일, When 은 이벤트나 동작, Then 은 기대 결과다. 단계를 이을 때 And·But 을 쓴다. 예: 검은 스웨터 3개가 있을 때(Given) 환불로 하나가 돌아오면(When) 4개가 돼야 한다(Then).](/svg/gherkin_given_when_then.svg)

```haskell
-- Feature > [Scenario] > [Step]
data Story    = Story { asA :: Role, iWant :: Goal, soThat :: Reason }
data Scenario = Scenario String [Step]
data Step     = Given String   -- 초기 상태 — 보통 과거에 일어난 일
              | When String    -- 이벤트·동작
              | Then String    -- 기대 결과
              | And String | But String

refund = Scenario "환불로 반품된 항목은 재고에 추가된다"
  [ Given "고객이 검은 스웨터를 샀다", And "재고에 검은 스웨터 3개"
  , When "환불로 검은 스웨터를 반환한다"
  , Then "재고에 검은 스웨터 4개" ]
```
