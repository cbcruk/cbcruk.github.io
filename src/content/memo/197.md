![.js 에서 JSX 를 허용하면 제공하는 모든 .js 파일을 JSX 가 있을지 몰라 전체 AST 변환해야 한다. 대부분의 .js 는 그런 변환 없이 브라우저에서 돌아야 하므로 Vite 는 JSX 를 .jsx 에서만 처리한다. 옮길 때는 JSX 태그가 있는 .js·.ts 파일을 찾아 git mv 로 확장자 끝에 x 를 붙인다 — 히스토리가 이어진다.](/svg/vite_jsx_extension.svg)

```haskell
-- Vite 는 JSX 를 .jsx 에서만: .js 까지 허용하면 모든 .js 를 전체 AST 변환해야 한다
needsTransform :: File -> Bool
needsTransform f = ext f `elem` [".jsx", ".tsx"]

-- 옮길 때: JSX 태그가 있는 .js·.ts 를 골라 git mv 로 x 를 붙인다
renames :: [File] -> [Command]
renames files = [gitMv f (f ++ "x") | f <- files, ext f `elem` [".js", ".ts"], hasJsxTag f]
-- find src -type f | grep "\.[jt]s$" | xargs -n1 grep -HE "^[^*\n]*(<\/?[a-zA-Z]*>)[\s\w]*$" | cut -d: -f1 | uniq | awk '{print "git mv "$1" "$1"x"}' | sh
```
