![영업시간에 따라 결과가 달라지는 purchase 를 테스트한다. 각 테스트 전에 useFakeTimers 로 Date·setTimeout 을 가짜로 바꾸고, setSystemTime 으로 13시를 넣으면 Success, 19시를 넣으면 Error 를 기대한다. 끝나면 useRealTimers 로 되돌린다. Vitest 와 Jest 모두 @sinonjs/fake-timers 위에 있어 API 이름만 vi·jest 로 다르다.](/svg/fake_timers_system_time.svg)

```haskell
-- 시각에 따라 결과가 달라지는 함수를 시각을 정해 놓고 테스트한다
purchase :: Time -> Result
purchase t | openHours t = Success
           | otherwise   = Error

beforeEach useFakeTimers        -- Date · setTimeout 등을 가짜로 (vi / jest 같은 이름)
afterEach  useRealTimers

it "영업시간"   (setSystemTime (date 2000 1 1 13) >> purchase' `shouldBe` Success)
it "영업시간 외" (setSystemTime (date 2000 1 1 19) >> purchase' `shouldBe` Error)
-- 둘 다 @sinonjs/fake-timers 기반
```
