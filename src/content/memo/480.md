![Props<TRow> 와 넘긴 props 를 칸마다 나란히 놓는다. rows: TRow[] 자리에는 { name: string }[] 이 와서 배열 안의 맨몸 TRow 자리에서 { name: string } 을 후보로 줍는다. renderRow 의 row 는 타입을 안 적었으니 주울 게 없다. extends Record<string, any> 는 넘긴 값이 아니라 후보가 아니다. 후보에서 고른 TRow 를 제약에 맞춰 보고, 안 맞으면 TRow 를 제약으로 바꿔 끼운 채 검사해 에러를 낸다. 후보로 TRow = { name: string } 이 정해지면 그 타입이 거꾸로 renderRow 의 row 로 흘러가서 row.name 을 쓸 수 있다.](/svg/generic_infer_collect.svg)

```haskell
-- 제네릭 컴포넌트: <TRow extends Record<string, any>> 로 넘긴 rows 에서 row 타입을 줍는다
table :: (row <: Record String Any) => { rows :: [row], renderRow :: row -> Int -> Node } -> Node
table { rows, renderRow } = tbody (zipWith renderRow rows [0..])

-- 1 줍기: 선언(Props<TRow>)과 넘긴 값을 칸마다 나란히 놓고, 맨몸 TRow 자리에서 후보를 줍는다
infer { rows = [{ name = "lee" }] }  -- [TRow] ↔ [{ name :: String }] → 후보 { name :: String }
--   renderRow 의 row 는 타입을 안 적어 주울 게 없다. extends 는 넘긴 값이 아니라 후보가 아니다
--   정해진 TRow 가 거꾸로 renderRow 로 흘러가 row.name 이 된다

-- 2 고르기: 후보가 여럿이면 자리로 — 내주는 쪽(공변)이 받는 쪽(반변)에 들어가면 공변이 이긴다
pick { rows = dogs, renderRow = \(row :: Animal) (i :: Int) -> … } == Dog      -- 다 적음: 반변 후보
pick { rows = dogs, renderRow = \(row :: Animal) -> … }            == Animal   -- 덜 적음: 공변 후보, 공통 상위
--   화살표 함수 리터럴일 때 얘기다. 이미 만든 함수면 덜 적어도 Dog, function 표현식은 다 적어도 Animal

-- 3 두 번째로 쓰는 자리는 NoInfer 로 줍기에서 뺀다 (TS 5.4+)
type Props row = { rows :: [row], renderRow :: row -> Int -> Node, selectedRow :: Maybe (NoInfer row) }
--   없으면 selectedRow { name, age } 도 후보가 돼 union 으로 넓어지고 에러가 안 난다

-- 4 extends Record<string, any> 는 원시값만 막는다 (= object)
--   Record<string, unknown> 은 type 별칭 객체만 — interface·배열·함수도 막힌다
-- 같은 패턴: downshift Combobox<T> 의 items → renderItem item
```
