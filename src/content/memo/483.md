![Image 의 src 타입은 Exclude<T, ''> 이다. T extends string 제약이 있으면 src="" 를 넘길 때 T 가 리터럴 '' 로 추론돼 Exclude<'', ''> 가 never 가 되어 막히고, "ab" 는 그대로 통과한다. 제약을 빼면 T 가 string 으로 넓어져 '' 도 통과한다. 또 string 타입 변수를 넘기면 T = string 이라 Exclude<string, ''> 도 string 이어서 값이 '' 여도 통과한다 — 인자 타입이 리터럴 '' 일 때만 막는 가드다.](/svg/non_empty_string_literal.svg)

```haskell
-- 빈 문자열 src 를 타입으로 막는다
type NonEmptyString t = Exclude t ""
image :: (t <: String) => { src :: NonEmptyString t } -> Element
-- t <: String 제약이 있어야 넘긴 리터럴을 그대로 줍는다 (빼면 t = String 으로 넓어져 "" 도 통과)

infer (image { src = "" })   -- t = "" → Exclude "" "" = never   ✗
infer (image { src = "ab" }) -- t = "ab"                          ✓
infer (image { src = s })    -- s :: String → t = String → String ✓ 값이 "" 여도
-- 인자 타입이 리터럴 "" 일 때만 막는 가드다 (const e: '' = '' 도 막힌다)

-- 왜 리터럴로 남나: 들어갈 자리가 primitive 제약을 가진 타입 변수면 리터럴 문맥으로 본다
```
