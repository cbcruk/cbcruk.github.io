![데이터가 없으면 컴포넌트가 promise 를 throw 한다 — 예외와 같은 메커니즘이다. 가장 가까운 Suspense 가 그것을 잡아 fallback 을 보이고, promise 가 resolve 되면 다시 렌더한다. throw fetch() 는 렌더할 때마다 새 promise 를 만들므로, 공식 경로는 캐시된 같은 promise 를 use 로 읽는 것이다.](/svg/suspense_throw_promise.svg)

```haskell
-- Suspense: 렌더가 promise 를 "던지면" 잡아서 기다린다 — 예외와 같은 메커니즘
render :: Component -> Either (Promise a) Html
render c = case cached c of
  Nothing -> Left (fetchData c)      -- throw promise
  Just d  -> Right (view d)

suspense :: Html -> Component -> IO Html
suspense fallback c = case render c of
  Left p  -> show fallback >> await p >> suspense fallback c   -- resolve 되면 다시 렌더
  Right h -> pure h

-- throw fetch() 는 렌더마다 새 promise — 공식 경로: 캐시된 같은 promise 를 use 로
```
