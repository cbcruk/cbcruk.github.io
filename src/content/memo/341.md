![불투명한 바탕 위에 색을 α 만큼 덮으면 결과 = 덮는색·α + 바탕·(1 − α) 다. 덮는 색이 흰색(255)이면 α = (목표 − 바탕) / (255 − 바탕) 으로 역산된다. 검정 위에서 #D1D7DE 를 만들려면 R·G·B 가 각각 0.82·0.84·0.87 이라 하나의 α 로는 정확히 못 맞춘다 — 평균 0.84 를 쓰면 rgb(214, 214, 214) 가 나오고 목표는 rgb(209, 215, 222) 다.](/svg/white_overlay_alpha.svg)

```haskell
-- 바탕 위에 흰색을 몇 % 덮어야 목표색이 되나: 합성식을 α 에 대해 푼다
-- 결과 = 덮는색·α + 바탕·(1 − α)   (바탕이 불투명할 때)
alpha :: Channel -> Channel -> Double
alpha base target = (target - base) / (255 - base)    -- 덮는색 = 흰색 255

alphas = zipWith alpha (rgb "#000000") (rgb "#D1D7DE") -- [0.82, 0.84, 0.87]
css    = "rgba(255, 255, 255, " ++ fixed 2 (mean alphas) ++ ")"   -- rgba(255, 255, 255, 0.84)

-- 채널별 α 가 다르면 평균 하나로는 정확히 못 맞춘다
over 0.84 white black == rgb 214 214 214   -- 목표는 rgb 209 215 222
```
