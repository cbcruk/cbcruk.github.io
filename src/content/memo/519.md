Date.getDay() - **로컬 시간** 기준 요일 반환 (0=일요일, 6=토요일)[^519-getday]

```javascript
new Date().getDay() // 0~6
new Date(2024, 11, 25).getDay() // 3 (수요일) — 월은 0부터 시작
new Date('2024-12-25').getDay() // ⚠ 날짜만 쓴 문자열은 UTC 자정 → UTC보다 느린 시간대(미국 등)에선 2

const days = ['일', '월', '화', '수', '목', '금', '토']
days[new Date().getDay()] // 오늘 요일
```

---

[^519-getday]: [Date.prototype.getDay() - MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/getDay): *"returns the day of the week for this date according to local time, where 0 represents Sunday."* / [Date time string format - MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date#date_time_string_format): *"When the time zone offset is absent, date-only forms are interpreted as a UTC time and date-time forms are interpreted as a local time."*
