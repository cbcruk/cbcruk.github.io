![getDay 는 로컬 시간 기준 요일을 0(일)~6(토)으로 준다. new Date(2024, 11, 25) 는 월이 0 부터라 12월 25일 로컬 자정이고 수요일(3)이다. new Date("2024-12-25") 처럼 날짜만 쓴 문자열은 UTC 자정으로 읽혀, UTC 보다 느린 시간대(미국 등)에선 로컬로 24일 저녁이라 화요일(2)이 나온다. 요일 이름은 [일, 월, 화, 수, 목, 금, 토] 배열에 getDay 로 꺼낸다.](/svg/getday_local_vs_utc.svg)

```haskell
-- 로컬 시간 기준 요일 (0 = 일, 6 = 토)
getDay :: Date -> Int

getDay (local 2024 11 25) == 3          -- 수요일. 월은 0 부터
getDay (parse "2024-12-25") == 2        -- UTC 보다 느린 시간대(미국 등)에서
  -- 날짜만 쓴 문자열은 UTC 자정, 날짜+시각은 로컬로 읽는다

dayName d = ["일", "월", "화", "수", "목", "금", "토"] !! getDay d
```
