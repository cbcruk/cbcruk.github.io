![업로드 크기 제한처럼 크기만 중요한 테스트에는 mkfile 로 원하는 크기의 파일을 만든다. 내용은 0 으로 채워져 있어 확장자가 .pdf 여도 열리는 PDF 는 아니다 — 크기 관련 동작만 확인할 수 있다.](/svg/mkfile_sized.svg)

```haskell
-- 크기만 중요한 테스트용 파일 (업로드 제한 등)
mkfile :: Size -> Path -> IO ()
mkfile n path = writeFile path (replicate n '\0')   -- 내용은 0 — 확장자가 .pdf 여도 열리는 PDF 는 아니다

-- mkfile 100m some100mfile.pdf
```
