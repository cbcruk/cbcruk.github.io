![autocomplete="one-time-code" 는 이 칸이 일회용 코드라고 브라우저에 알리는 힌트라, SMS 로 온 코드를 OS·키보드가 제안한다. JS 로 직접 받으려면 WebOTP 의 navigator.credentials.get({ otp: { transport: ["sms"] } }) 를 쓰는데, SMS 마지막 줄이 @도메인 #코드 형식이어야 한다.](/svg/otp_input_webotp.svg)

```haskell
-- OTP 칸: 두 길
-- 1 힌트: <input inputmode="numeric" autocomplete="one-time-code" pattern="\d{6}"> — OS·키보드가 제안
-- 2 WebOTP: JS 로 직접 받는다. SMS 마지막 줄이 "@도메인 #코드" 여야 한다
webOtp :: Domain -> Sms -> Maybe Code
webOtp origin sms = case words (last (lines sms)) of
  ['@' : d, '#' : code] | d == origin -> Just code
  _                                    -> Nothing
```
