![interface 안에 이름 없는 (a, b) => 반환 형태의 호출 시그니처를 두면 그 인터페이스가 함수 타입이 된다. const sum: MathFn = (a, b) => a + b 처럼 변수에 타입을 붙이면 매개변수 a·b 의 타입은 문맥에서 추론된다.](/svg/interface_call_signature.svg)

```haskell
-- interface 의 호출 시그니처 = 함수 타입
type MathFn = Double -> Double -> Double      -- interface MathFn { (a: number, b: number): number }

sum :: MathFn
sum a b = a + b                                -- const sum: MathFn = (a, b) => a + b — a·b 는 문맥에서 추론
```
