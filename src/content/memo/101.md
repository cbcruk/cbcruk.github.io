```sh
# 마지막 커밋 해시
git log --pretty=format:'%h' -n 1
```

`%h` 는 축약 해시 자리표시자다.[^101-pretty]

```sh
# 유저정보
git config user.name
git config user.email
```

---

[^101-pretty]: [git-scm — PRETTY FORMATS](https://git-scm.com/docs/pretty-formats): `%h` — *"abbreviated commit hash"*
