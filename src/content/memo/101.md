![git log --pretty=format:%h -n 1 은 마지막 커밋 하나의 축약 해시를 찍는다 — %h 가 축약 해시 자리표시자다. git config user.name 과 user.email 은 지금 설정된 커밋 작성자 정보를 보여 준다.](/svg/git_short_hash.svg)

```haskell
-- 마지막 커밋의 축약 해시
lastHash :: IO String
lastHash = abbrev . hash . head <$> gitLog       -- git log --pretty=format:'%h' -n 1  (%h = abbreviated commit hash)

-- 커밋 작성자: git config user.name · git config user.email
```
