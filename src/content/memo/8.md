[Quick tip: reusable Array search predicates - JASON Format](https://jasonformat.com/reusable-array-search-predicates/)

```js
arr.filter(callback(element[, index[, array]])[, thisArg])
```

배열 메서드의 2번째 인자 `thisArg`는 콜백의 `this`가 된다 — 비교할 값을 `this`로 받는 `function` 하나를 여러 검색에 재사용하는 트릭. 화살표 함수는 `this`가 없어 `thisArg`가 무시된다[^8-1]. 단 화살표 함수보다 느릴 수 있다[^8-2].

---

[^8-1]: [Array — Iterative methods | MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array#iterative_methods): *"The `thisArg` argument is irrelevant for any `callbackFn` defined with an arrow function, as arrow functions don't have their own `this` binding."*
[^8-2]: [Quick tip: reusable Array search predicates](https://jasonformat.com/reusable-array-search-predicates/): *"the performance of this approach can be worse than using an Arrow Function without some restrictions."*
