![npm install 실패는 원인에 따라 플래그가 다르다. Node 버전이 engines 와 안 맞는 경우 npm 은 기본이 경고(EBADENGINE)뿐이라, 막혔다면 engine-strict 가 켜진 것이니 --engine-strict=false 로 끈다. --ignore-engines 는 yarn 플래그라 npm 은 무시한다. 가장 흔한 peer dependency 충돌(예: React 18 프로젝트에 peer 가 react 16.8·17 인 react-beautiful-dnd — 실제로는 돈다)은 --legacy-peer-deps 로 peer 를 무시한다. 프로젝트 전체에 적용하려면 .npmrc 에 legacy-peer-deps=true. --force 는 마지막 수단이다.](/svg/npm_install_flags.svg)

```haskell
-- npm install 이 실패하면 원인으로 플래그를 고른다
flag :: InstallError -> Flag
flag EngineMismatch = "--engine-strict=false"   -- 기본은 경고(EBADENGINE)뿐 — 막혔다면 engine-strict 가 켜진 것
                                                -- --ignore-engines 는 yarn 플래그, npm 은 무시
flag PeerConflict   = "--legacy-peer-deps"      -- 가장 흔함. peerDependencies 를 통째로 무시 (npm 3~6 처럼)
flag _              = "--force"                 -- 마지막 수단, 권장 안 함

-- peer 충돌의 전형: 공식 지원은 안 하지만 실제로는 돈다
deps = [("react", "^18.2.0"), ("react-beautiful-dnd", "^13.1.1")]   -- peer: react@^16.8 || ^17

-- 프로젝트 전체: echo "legacy-peer-deps=true" > .npmrc
```
