![RenderPropNames 는 Title | Content | Actions 다. 매핑 타입이 멤버를 하나씩 K 로 돌고, as 가 키 이름을 `render${K}` 로 바꿔서 renderTitle·renderContent·renderActions 세 prop 이 생긴다. 각각 ReactNode 를 돌려주는 함수다. 이름을 바꾸는 as 는 TS 4.1 부터.](/svg/template_literal_keys.svg)

```haskell
-- 템플릿 리터럴 타입으로 prop 이름을 만든다 (TS 4.1+ key remapping)
type Names = "Title" | "Content" | "Actions"
type RenderProps = { [k in Names as "render" ++ k]: () -> Node }
-- == { renderTitle :: () -> Node, renderContent :: () -> Node, renderActions :: () -> Node }

dialog { renderTitle, renderContent, renderActions } =
  div "root" [ div "content" [renderTitle (), renderContent ()]
             , div "actions" [renderActions ()] ]
```
