![Google Optimize 의 Redirect 테스트는 리다이렉트하면서 utm_expid 같은 측정 정보를 query 에 붙인다. 우리 코드가 리다이렉트 URL 을 바꾸며 query 를 새로 만들어 버려 그 정보가 날아갔고, 기능은 돌지만 세션이 잡히지 않았다. replace 할 때 기존 query 를 이어 붙이도록 고쳐 해결했다. Charles 로 배포 없이 확인했다. Optimize 는 2023년 9월 30일 종료됐다.](/svg/redirect_keep_query.svg)

```haskell
-- 리다이렉트에서 query 를 갈아끼우면 거기 실린 측정 정보(utm_expid)가 사라진다
redirectBroken, redirect :: Url -> Query -> Url
redirectBroken url new = url { query = new }               -- 세션이 안 잡혔다
redirect       url new = url { query = query url <> new }  -- 이전 query 를 이어 붙인다

-- Google Optimize Redirect 테스트에서 겪음 (2023-09-30 종료) · Charles 로 배포 없이 확인
```
