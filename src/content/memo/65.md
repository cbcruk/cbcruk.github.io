![npm install --save ../foo/bar 처럼 로컬 디렉터리를 설치하면 package.json 에 상대 경로로 정규화되어 "bar": "file:../foo/bar" 로 저장된다. 레지스트리를 거치지 않고 파일 시스템의 패키지를 의존성으로 건다.](/svg/npm_file_dependency.svg)

```haskell
-- 로컬 디렉터리를 의존성으로 — 상대 경로로 정규화되어 저장된다
dep :: Path -> (Name, Spec)
dep path = (packageName path, "file:" ++ relative path)

dep "../foo/bar" == ("bar", "file:../foo/bar")   -- npm install --save ../foo/bar
```
