`file:` 로 파일 시스템의 패키지 디렉터리를 의존성으로 건다 — `npm install --save ../foo/bar` 로 설치하면 상대 경로로 이렇게 저장된다.[^65-local]

```json
{
  "dependencies": {
    "bar": "file:../foo/bar"
  }
}
```

[^65-local]: [package.json | npm Docs](https://docs.npmjs.com/cli/v11/configuring-npm/package-json#local-paths): *"As of version 2.0.0 you can provide a path to a local directory that contains a package."* / *"in which case they will be normalized to a relative path and added to your `package.json`."*
