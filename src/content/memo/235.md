![빌드할 때 버전에 꼬리표를 붙이려면 date +%s 로 1970-01-01 UTC 이후 초를 쓸 수 있다. 실제로는 .env 에서 REACT_APP_VERSION=1.0.0-${TURBO_HASH} 처럼 turbo 가 태스크마다 넣어 주는 해시를 dotenv-expand 로 펼쳐 쓴다 — 내용이 같으면 해시도 같다.](/svg/build_version_suffix.svg)

```haskell
-- 빌드 버전에 꼬리표
version :: Either Timestamp TurboHash -> String
version (Left t)  = "1.0.0-" ++ show t   -- $(date +%s): 1970-01-01 UTC 이후 초, 빌드마다 다르다
version (Right h) = "1.0.0-" ++ h        -- .env 의 ${TURBO_HASH} — 실제로는 이쪽 (dotenv-expand)
```
