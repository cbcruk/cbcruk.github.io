![Ark UI 는 컴포넌트를 data-scope 로, 그 안의 부품을 data-part 로 표시한다. 슬라이더라면 [data-scope=slider][data-part=thumb], track, control 처럼 두 속성의 조합으로 어떤 부품이든 클래스 이름 없이 스타일을 건다.](/svg/data_scope_part.svg)

```haskell
-- Ark UI: 컴포넌트는 data-scope, 그 안의 부품은 data-part
select :: Scope -> Part -> Selector
select scope part = "[data-scope='" ++ scope ++ "'][data-part='" ++ part ++ "']"

map (select "slider") ["thumb", "track", "control"]   -- 클래스 이름 없이 부품마다 스타일
```
