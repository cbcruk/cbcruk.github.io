![플러그인 시스템은 코어가 플러그인을 등록받아 정해진 지점에서 불러 주는 구조다. 기능을 코어에 직접 넣지 않고 플러그인으로 더하므로, 코어를 고치지 않고 안전하게 확장할 수 있고 추가 유지 보수 부담이 코어에 쌓이지 않는다.](/svg/plugin_system.svg)

```haskell
-- 플러그인 시스템: 코어는 등록받은 플러그인을 정해진 지점에서 부를 뿐
type Plugin = Core -> Core

register :: Plugin -> [Plugin] -> [Plugin]
register = (:)

run :: [Plugin] -> Core -> Core
run plugins core = foldr ($) core plugins      -- 코어를 고치지 않고 기능을 더한다
```
