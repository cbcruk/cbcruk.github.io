![{ a: 1 } & { b: 2 } 같은 교차 타입이나 ComponentProps 는 에디터 툴팁에 별칭 이름이나 & 로 이어진 조각으로 보인다. 매핑 타입 { [K in keyof T]: T[K] } 가 속성을 한 객체로 다시 모으고, 거기에 & {} 를 붙여야 별칭 이름 대신 펼친 모양 { a: 1; b: 2 } 이 뜬다. 왜 & {} 가 필요한지는 공식 설명이 없는 컴파일러의 특이점이다.](/svg/prettify_type.svg)

```haskell
-- 교차 타입을 한 객체로 펼쳐 보여준다 (에디터 툴팁·에러 메시지용)
type Prettify t = { [k in keyof t]: t ! k } & {}
-- 매핑 타입이 속성을 다시 모은다
-- & {} 가 있어야 별칭 이름(Prettify<…>) 대신 펼친 모양이 뜬다 — & unknown 도 같다
-- 왜 그런지는 공식 설명이 없다: "a quirk of the TypeScript compiler" — Total TypeScript, The Prettify Helper (tsc 5.9.3 에서 확인)

show (Prettify ({ a :: 1 } & { b :: 2 })) == "{ a: 1; b: 2 }"
p :: Prettify (ComponentProps "div")
```
