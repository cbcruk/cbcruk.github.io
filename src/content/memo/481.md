교차 타입을 한 객체로 펼쳐 보여준다 — 매핑 타입이 속성을 다시 모으고, `& {}` 가 있어야 별칭 이름(`Prettify<…>`) 대신 펼친 모양(`{ a: 1; b: 2 }`)이 뜬다.[^prettify]

```ts
import * as React from 'react'

type Prettify<T> = {
  [K in keyof T]: T[K]
} & {}

type T = React.ComponentProps<'div'>

type P = Prettify<T>
```

---

[^prettify]: `& {}` 를 빼면 에러 메시지에 별칭 이름이 그대로 나온다(tsc 5.9.3). `& unknown` 도 같다. 왜 그런지는 공식 설명이 없다 — [Total TypeScript — The Prettify Helper](https://www.totaltypescript.com/concepts/the-prettify-helper): *"It's not clear why using a mapped type and intersecting it with `{}` actually works. It's a quirk of the TypeScript compiler."*
