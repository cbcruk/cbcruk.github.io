같은 이름은 `dependencies` 에 한 번만 들어간다 — `<별칭>@npm:<이름>@<버전>` 으로 별칭을 달면 여러 버전이 나란히 설치된다.[^249-alias]

```shell
yarn add react-tooltip-5@npm:react-tooltip@5.8.3
```

```json
{
  "react-tooltip-5": "npm:react-tooltip@5.8.3"
}
```
