![dependencies 에서 이름은 키라 같은 이름은 한 번만 들어간다. <별칭>@npm:<이름>@<버전> 으로 설치하면 별칭이 키가 되어 같은 패키지의 여러 버전이 나란히 설치되고, 코드에서는 별칭으로 import 한다. 별칭은 내 프로젝트에만 적용되고 전이 의존성의 이름은 바꾸지 않는다.](/svg/npm_alias_versions.svg)

```haskell
-- dependencies 는 이름이 키 — 같은 이름은 하나뿐. 별칭을 키로 쓰면 여러 버전이 나란히
alias :: Name -> Package -> Version -> (Name, Spec)
alias a p v = (a, "npm:" ++ p ++ "@" ++ v)

-- yarn add react-tooltip-5@npm:react-tooltip@5.8.3
alias "react-tooltip-5" "react-tooltip" "5.8.3" == ("react-tooltip-5", "npm:react-tooltip@5.8.3")
-- 별칭은 내 프로젝트에만, 전이 의존성 이름은 바꾸지 않는다
```
