![Ambient Light Sensor 권한이 거부가 아니면 센서를 시작하고, reading 이벤트마다 illuminance(lux, E)를 받아 EV = log₂(E × ISO / C) 로 노출값을 구한다. ISO 는 100, C 는 입사광 노출계 교정 상수로 평판 수광부면 250 을 쓴다.](/svg/ambient_light_ev.svg)

```haskell
-- 조도계 노출 공식에 센서 lux 를 넣는다
ev :: Double -> Double -> Double -> Int
ev iso c lux = round (logBase 2 (lux * iso / c))   -- EV = log₂(E·S / C)

reading :: Lux -> Int
reading = ev 100 250      -- ISO 100 · C = 250 (입사광, 평판 수광부)

-- permissions.query 'ambient-light-sensor' 가 denied 가 아니면
-- new AmbientLightSensor { frequency = 20 } → 'reading' 마다 reading illuminance
```
