![tags 가 JSON 배열인 행들을 json_each 로 원소 하나당 한 행으로 펼치고, 태그로 묶어 개수를 센 뒤 빈도 내림차순·이름 오름차순으로 정렬한다. 다시 JSON 배열로 모을 때 바깥 ORDER BY 는 집계 안의 순서를 보장하지 않으므로, json_group_array(tag ORDER BY …) 처럼 집계 안에 ORDER BY 를 넣는다(SQLite 3.44+).](/svg/sqlite_json_tag_frequency.svg)

```haskell
-- JSON 배열 태그를 펼쳐 빈도순으로
frequencies :: [[Tag]] -> [(Tag, Int)]
frequencies = sortOn (\(t, n) -> (Down n, t))          -- ORDER BY frequency DESC, tag ASC
            . map (\g -> (head g, length g)) . group . sort
            . concat                                    -- FROM example, json_each(example.tags)

-- 다시 JSON 배열로 모을 때: 바깥 ORDER BY 는 집계 안 순서를 보장하지 않는다
-- json_group_array(tag ORDER BY frequency DESC, tag ASC)   -- 집계 안 ORDER BY, SQLite 3.44+
```
