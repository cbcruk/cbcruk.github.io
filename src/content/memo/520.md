![윈도우즈에서 외부 경로의 파일을 읽을 때, 윈도우즈는 / 와 \ 를 둘 다 구분자로 받지만 path 메서드는 \ 로 만든다. 문자열로 쓰려면 슬래시를 쓰거나 백슬래시를 이스케이프하고, 권장은 path.join(USERPROFILE, Documents, file.txt) 다. path.normalize 는 .. 를 풀기만 해서 ../../etc/passwd 는 그대로 남는다 — 사용자 입력이면 path.resolve(base, input) 결과가 base 와 구분자로 시작하는지 확인한다.](/svg/node_path_windows.svg)

```haskell
-- 윈도우즈 외부 경로: / 와 \ 를 둘 다 구분자로 받지만 path 메서드는 \ 로 만든다
p1 = "C:/Users/username/Documents/file.txt"
p2 = "C:\\Users\\username\\Documents\\file.txt"            -- 이스케이프
p3 = join [env "USERPROFILE", "Documents", "file.txt"]     -- 권장 (크로스 플랫폼)
p4 = resolve "../../Documents/file.txt"                    -- 절대 경로로

-- normalize 는 트래버설을 막지 못한다 — .. 를 풀기만 한다
normalize "../../etc/passwd" == "../../etc/passwd"

-- 사용자 입력이면
safe :: Path -> Path -> Bool
safe base input = (base ++ sep) `isPrefixOf` resolve base input
```
