![Page 가 Container 의 children 으로 요소가 아니라 Body 컴포넌트 자체를 넘긴다. Container 는 데이터(id = 1234)를 갖고 있다가 <Child id={id} /> 로 렌더한다 — 컨테이너는 데이터를, 프레젠테이션 Body 는 화면을 맡는다. 컴포넌트는 children({ id }) 처럼 함수로 부르지 않고 JSX 로만 쓴다.](/svg/children_as_component.svg)

```haskell
-- children 으로 요소가 아니라 컴포넌트를 넘긴다
container :: ({ id :: String } -> Element) -> Element
container child = jsx child { id = "1234" }    -- 컨테이너가 데이터를 쥐고
body { id } = text id                          -- 프레젠테이션이 그린다
page = container body                          -- <Container>{Body}</Container>

-- 컴포넌트는 JSX 로만: child { id } 처럼 함수로 부르지 않는다
```
