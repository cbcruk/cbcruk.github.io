![vi.mock 은 파일 맨 위로 끌어올려져 바깥 변수를 못 본다. 그래서 vi.hoisted 안에서 MockResizeObserver 를 만들고 vi.mock 이 그걸 resize-observer-polyfill 의 default 로 넣는다. new 로 불리므로 구현은 화살표가 아니라 function 이다 — 화살표면 is not a constructor. 생성될 때마다 콜백과 observer 를 배열에 쌓아 두고, 테스트에서 triggerResize(entries, index) 로 원하는 observer 의 콜백을 직접 부른다. beforeEach 에서 배열을 비운다.](/svg/resize_observer_mock.svg)

```haskell
-- vi.mock 은 맨 위로 끌어올려져 바깥 변수를 못 본다 → vi.hoisted 로 먼저 만든다
(mockResizeObserver, MockResizeObserver) = hoisted $ do
  observers <- newRef []
  let ctor = fn (\callback -> do                 -- new 로 불린다: 화살표가 아니라 function
               let o = { observe = fn, unobserve = fn, disconnect = fn }
               modify observers (++ [(callback, o)])
               pure o)
  pure ( { triggerResize = \entries i -> do (cb, o) <- (!! i) <$> read observers
                                            cb entries o
         , reset = write observers [] }
       , ctor )

mock "resize-observer-polyfill" { default = MockResizeObserver }

beforeEach (reset mockResizeObserver)
it "handles resize" (triggerResize mockResizeObserver [{ target = div, contentRect = { width = 100 } }] 0)
```
