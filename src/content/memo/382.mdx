![Figma 는 흩어진 권한 로직(불필요한 복잡성·계층 권한 비효율·DB 부하·여러 진실 소스)을 JSON 으로 직렬화되는 DSL 로 모았다. 식은 셋뿐이다: [필드, 연산자, 값] 꼴의 이항 식, 그리고 그걸 묶는 and·or. 예: file.id 가 null 이 아니고 team.permission 이 open 이면. 정책이 데이터라 어디로든 보낼 수 있고, TypeScript 평가 엔진이 하나로 판정한다.](/svg/figma_permissions_dsl.svg)

```haskell
-- Figma 권한 DSL: 정책을 JSON 으로 직렬화되는 식으로, 평가는 TypeScript 엔진 하나로
-- (이전: 불필요한 복잡성 · 계층 권한 비효율 · DB 부하 · 여러 진실 소스)
data Expr = Binary Field Op Value   -- ['file.id', '<>', null]
          | And [Expr]              -- { and: [...] }
          | Or  [Expr]              -- { or: [...] }

eval :: Row -> Expr -> Bool
eval r (Binary f op v) = apply op (r ! f) v
eval r (And es)        = all (eval r) es
eval r (Or es)         = any (eval r) es

canView = And [ Binary "file.id" "<>" Null, Binary "team.permission" "=" "open" ]
```
