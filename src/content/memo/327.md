![종료 시각을 지금부터 60초 뒤로 주고 Countdown 을 렌더하면 처음엔 비어 있다. vi.useFakeTimers 로 setTimeout·setInterval·Date 를 가짜로 바꾼 뒤 act 안에서 advanceTimersByTime(10000) 으로 10초를 밀면 00:00:50, 50초를 더 밀면 00:00:00 이 된다. advanceTimersByTime 은 그 시간 안에 걸린 타이머를 전부 실행한다. 끝나면 useRealTimers 로 되돌린다.](/svg/countdown_fake_timers.svg)

```haskell
-- 타이머를 직접 민다: useFakeTimers 가 setTimeout·setInterval·Date 를 가짜로 바꾼다
advanceTimersByTime :: Ms -> Clock -> Clock   -- 그 시간 안에 걸린 타이머를 전부 실행 (또는 큐가 빌 때까지)

test = do
  render (countdown { endAt = now + 60000 })
  shown `shouldBe` ""
  act (advanceTimersByTime 10000) ; shown `shouldBe` "00:00:50"
  act (advanceTimersByTime 50000) ; shown `shouldBe` "00:00:00"
-- beforeEach useFakeTimers · afterEach useRealTimers
```
