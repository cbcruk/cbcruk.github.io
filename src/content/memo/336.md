![정규식 문자 클래스에 나열한 기호(!@#$%^&*()_+-=[]{};':"\|,.<>/?)를 전부 지운다. 영문·숫자·한글·공백은 목록에 없으니 남는다. Hello_World123! 안녕하세요? 는 HelloWorld123 안녕하세요 가 된다 — 밑줄도 목록에 있어 지워진다.](/svg/remove_special_chars.svg)

```haskell
-- 목록에 든 특수 기호만 지운다 (영문·숫자·한글·공백은 남는다)
removeSpecialCharacters :: String -> String
removeSpecialCharacters = filter (`notElem` specials)
  where specials = "!@#$%^&*()_+-=[]{};':\"\\|,.<>/?"

removeSpecialCharacters "Hello_World123! 안녕하세요?" == "HelloWorld123 안녕하세요"   -- _ 도 목록에 있다
```
