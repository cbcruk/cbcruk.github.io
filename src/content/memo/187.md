![new Blob(array) 로 다운로드 파일을 만들었는데 잘 안 됐다. 옵션에 type 을 빠뜨린 게 원인이었다 — new Blob(array, { type: "text/html" }) 처럼 MIME 타입을 함께 준다.](/svg/blob_type_option.svg)

```haskell
-- 다운로드용 Blob: 내용과 함께 MIME 타입을 준다
blob :: [Part] -> MimeType -> Blob
blob parts mime = Blob parts BlobOptions { type_ = mime }

blob array "text/html"     -- new Blob(array, { type : 'text/html' })
-- type 을 빠뜨렸을 때 다운로드가 잘 안 됐다
```
