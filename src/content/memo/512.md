![JS 의 Number 는 IEEE 754 64비트 부동소수점이다. 0.1 은 이진법으로 0.000110011… 이 끝없이 반복돼 가장 가까운 값으로 잘려 저장되고, 그 오차가 더해져 0.1 + 0.2 가 0.30000000000000004 가 된다. 피하는 길은 셋: 정수로 바꿔 계산 후 나누기, toFixed 로 자른 뒤 parseFloat, 비교할 때 크기에 비례한 허용 오차(EPSILON × 크기). EPSILON 은 1 근처에서만 맞는다 — 1.1 + 0.1 − 1.2 는 정확히 EPSILON 이라 그대로 쓰면 < 비교가 false 다. 정밀 계산은 decimal.js·big.js. Python·Java·C++ 도 같다.](/svg/float_point_error.svg)

```haskell
-- JS Number = IEEE 754 64비트 (Python·Java·C++ 의 double 과 같다)
0.1 + 0.2 /= 0.3                   -- 0.30000000000000004
-- 0.1 은 이진법으로 0.0001100110011… 무한 반복 → 가장 가까운 값으로 잘려 저장된다

-- 피하는 길
viaInt    = (1.1 * 10 + 0.1 * 10) / 10          -- 정수로 바꿔 계산
viaFixed  = parseFloat (toFixed 1 (1.1 + 0.1))  -- 잘라서
close a b = abs (a - b) < epsilon * max (abs a) (abs b)   -- 비교는 크기에 비례한 허용 오차

abs (1.1 + 0.1 - 1.2) == epsilon   -- 그래서 `< epsilon` 만 쓰면 False
-- 정밀 계산: decimal.js · big.js · bignumber.js
```
