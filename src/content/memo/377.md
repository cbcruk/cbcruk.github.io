![모노레포에서 서비스별로 따로 배포하려면 워크플로마다 on.push.paths 를 건다. 푸시에 바뀐 파일 중 하나라도 패턴(예: **.js)에 맞으면 그 워크플로가 실행되고, 하나도 안 맞으면 실행되지 않는다.](/svg/gha_paths_filter.svg)

```haskell
-- 모노레포에서 서비스별 배포: 워크플로마다 paths 필터
runs :: [Glob] -> [File] -> Bool
runs paths changed = any (\f -> any (`matches` f) paths) changed   -- 하나라도 맞으면 실행

-- on: push: paths: ['**.js']
runs ["**.js"] ["README.md", "services/a/index.js"] == True
runs ["**.js"] ["README.md"]                         == False
```
