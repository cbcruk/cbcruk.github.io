![서비스워커는 fetch 이벤트로 브라우저에서 나가는 요청을 받아 respondWith 로 응답을 직접 줄 수 있다 — 이게 MSW 같은 mock 의 원리다. 하지만 서비스워커는 브라우저 요청만 보므로 getServerSideProps 처럼 서버에서 나가는 요청은 nock 같은 도구로 Node 쪽에서 가로챈다. 직접 만들기보다 이미 잘 만든 라이브러리를 쓴다.](/svg/mock_where_intercept.svg)

```haskell
-- mock: 요청이 나가는 곳에서 가로챈다
intercept :: Origin -> Interceptor
intercept Browser = ServiceWorker   -- addEventListener('fetch', e => e.respondWith(mock(e.request))) — MSW 의 원리
intercept Server  = NodeHook        -- getServerSideProps 처럼 서버에서 나가는 요청 — nock
-- 원리는 간단하지만 이미 잘 만든 라이브러리가 있다 — 아이디어로만
```
