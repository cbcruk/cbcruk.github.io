![acorn 을 acorn-jsx 로 확장한 파서로 파일을 모듈로 파싱하고, 나온 AST 에 JSXIdentifier 노드가 하나라도 있으면 JSX 를 쓰는 파일로 본다. CRA 에서 Vite 로 옮길 때 .js 를 .jsx 로 바꿀 파일을 고르는 데 쓴다.](/svg/acorn_jsx_detect.svg)

```haskell
-- 이 .js 가 JSX 를 쓰나 (CRA → Vite 로 옮길 때 .jsx 로 바꿀 파일 고르기)
isReactComponent :: String -> Bool
isReactComponent = any isJSXIdentifier . universe   -- AST 어딘가에 JSXIdentifier 가 있나
                 . parseJSX Module Latest          -- acorn.Parser.extend(acorn-jsx)
```
