![2020년부터 모든 브라우저가 ::placeholder 를 지원한다. 그 전에는 Chrome·Safari·Opera 의 ::-webkit-input-placeholder, IE 의 :-ms-input-placeholder, 레거시 Edge 의 ::-ms-input-placeholder 를 따로 썼다. ::-ms-clear 와 ::-ms-reveal 은 IE·레거시 Edge 의 지우기·비밀번호 보기 버튼이다.](/svg/placeholder_selectors.svg)

```haskell
-- placeholder 스타일: 지금은 하나
placeholderSelector :: Browser -> Selector
placeholderSelector Modern     = "::placeholder"                 -- 2020 년부터 전 브라우저
placeholderSelector WebKit     = "::-webkit-input-placeholder"   -- Chrome · Safari · Opera (그 전)
placeholderSelector IE         = ":-ms-input-placeholder"
placeholderSelector LegacyEdge = "::-ms-input-placeholder"
-- IE · 레거시 Edge 전용 컨트롤: ::-ms-clear (지우기) · ::-ms-reveal (비밀번호 보기)
```
