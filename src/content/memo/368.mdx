![같은 URL 파싱인데 실패를 알리는 방식만 다르다. new URL(null) 은 TypeError 를 던지고, URL.canParse(null) 은 false 를 돌려주고, URL.parse(null) 은 null 을 돌려준다. parse 는 try...catch 로 생성자를 감싸거나 canParse 로 먼저 확인하던 것을 한 번에 한다. 두 번째 인자 base 로 상대 URL 을 해석한다.](/svg/url_parse_failure.svg)

```haskell
-- 같은 파싱, 실패를 알리는 방식만 다르다
new      :: String -> Url          -- 실패하면 TypeError 를 던진다
canParse :: String -> Bool         -- 실패하면 False
parse    :: String -> Maybe Url    -- 실패하면 null
parse s = if canParse s then Just (new s) else Nothing   -- try…catch 로 감싸던 걸 한 번에

new      null   -- throws TypeError
canParse null == False
parse    null == Nothing
-- 두 번째 인자 base: 상대 URL 을 해석할 기준. URL 객체도 문자열로 바꿔 받는다
```
