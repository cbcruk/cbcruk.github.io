![사람들이 슬랙에서 추천한 책을 구글시트에 기록한다. 슬랙에 /book 슬래시 커맨드를 만들어 요청 URL 에 구글 앱스 스크립트 웹 앱 URL 을 연결하면, 커맨드를 칠 때 슬랙이 그 URL 로 POST 하고 스크립트의 doPost 가 받은 값으로 시트에 행을 쓴다. 방법은 링크에 있고 여기엔 차례만 적었다.](/svg/slack_to_sheets_order.svg)

```haskell
-- 슬랙에서 추천한 책을 구글시트에 — 방법이 아니라 밟는 차례가 내용이다
book :: SlashCommand -> Sheet ()
book cmd = slashCommand "/book" cmd     -- 슬랙 커맨드 설정, 요청 URL 에 앱스 스크립트 웹 앱 연결
       >>= post appsScriptUrl           -- 슬랙이 POST 한다
       >>= doPost                       -- 받은 값으로 처리 (비동기 작업은 doPost 에서)
       >>= appendRow
```
