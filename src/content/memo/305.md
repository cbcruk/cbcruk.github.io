![서비스 계정 설정부터 정하고, Google Cloud 에서 프로젝트를 만들고, Google Sheets API 를 켜고, 서비스 계정을 만들어 키를 받고, 그 키를 환경 변수에 넣으면 google-spreadsheet 로 시트를 다룰 수 있다. 각 단계의 방법이 아니라 밟는 차례를 기억하려고 적어 둔 것이다.](/svg/google_sheets_setup_order.svg)

```haskell
-- Google Sheets API 를 쓰기까지 — 방법이 아니라 밟는 차례가 내용이다
setup :: GCP ()
setup = configureServiceAccount
     >> createProject          -- console.cloud.google.com
     >> enable SheetsApi
     >> createCredentials
     >> createServiceAccount
     >> createKey              -- 서비스 계정 키(JSON)
     >> setEnv                 -- 그다음 google-spreadsheet 로 시트를 조작한다
```
