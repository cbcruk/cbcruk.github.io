![git checkout -- 파일과 git restore 파일은 작업 트리의 파일을 인덱스 내용으로 되돌린다 — add 해 둔 변경은 남는다. git reset --hard 는 인덱스까지 HEAD 로 맞추고 작업 트리도 따라가 스테이지한 것까지 사라진다. git remote update 는 모든 리모트를 fetch 한다.](/svg/git_discard_targets.svg)

```haskell
-- 변경 버리기: 무엇으로 되돌리나
restore :: Index -> Head -> WorkTree -> WorkTree
restore idx _ _ = fromIndex idx          -- git checkout -- <file> · git restore <file> — add 해 둔 변경은 남는다

resetHard :: Head -> (Index, WorkTree)
resetHard h = (indexOf h, treeOf h)      -- git reset --hard — 인덱스까지 HEAD 로

-- git remote update: 모든 리모트를 fetch
```
