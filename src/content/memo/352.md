![크롬 인증서 경고(이 연결은 비공개로 설정되지 않았습니다, NET::ERR_CERT_…)에서 고급 → 계속이 없거나 번거로울 때, 페이지 아무 곳이나 클릭해 포커스를 준 뒤 입력창 없이 thisisunsafe 를 타이핑한다. 경고 페이지의 keypress 핸들러가 한 글자씩 BYPASS_SEQUENCE 와 대조하고, 다 맞으면 CMD_PROCEED 를 보낸다 — 계속을 누른 것과 같은 명령이다. 마지막 글자에서 넘어가고, 안 넘어가면 포커스가 주소창에 있는 것이니 클릭부터 다시.](/svg/thisisunsafe.svg)

```haskell
-- 로컬·테스트 서버에서 크롬 인증서 경고(NET::ERR_CERT_*)를 강제로 통과
-- 경고 페이지에 입력창이 없는 게 정상이다 — 페이지가 keypress 를 직접 받는다
onKeypress :: Char -> [Char] -> ([Char], Maybe Command)
onKeypress c typed
  | typed' == bypassSequence           = ([], Just CmdProceed)   -- "안전하지 않음(계속)" 과 같은 명령
  | typed' `isPrefixOf` bypassSequence = (typed', Nothing)
  | otherwise                          = ([], Nothing)
  where typed' = typed ++ [c]

bypassSequence = "thisisunsafe"

-- 절차: 1 경고 화면 아무 곳이나 클릭(포커스) 2 그대로 thisisunsafe 타이핑
-- 확인: 마지막 글자에서 넘어간다. 안 넘어가면 포커스가 주소창 — 1번부터
```
