![textarea·select·input 은 기본적으로 고정 크기라 내용이 넘치면 스크롤된다. CSS 한 줄 field-sizing: content 를 주면 내용에 맞춰 크기가 정해져, 글을 칠수록 textarea 가 늘어나고 input 도 글자 수만큼 넓어진다. JS 로 높이를 재던 자동 크기 조절이 필요 없다.](/svg/css_field_sizing.svg)

```haskell
-- CSS 한 줄로 내용 기반 크기 조절 — textarea 뿐 아니라 select·input 에도
size :: FieldSizing -> Element -> Size
size Fixed   el = defaultSize el      -- 기본: 고정 크기, 넘치면 스크롤
size Content el = contentSize el      -- 내용만큼 — JS 로 높이를 재던 자동 크기 조절이 필요 없다

-- textarea, select, input { field-sizing: content; }
```
