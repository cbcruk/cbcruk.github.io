![ModalProps 는 variant 가 no-title 인 것과, variant 가 title 이면서 title 문자열이 있는 것의 유니온이다. if (variant === no-title) 바깥 분기에선 props 가 title 멤버로 좁혀져 props.title 을 쓸 수 있다. variant 없이 쓰면 막히고, no-title 에 title 을 붙여도 막힌다 — 초과 속성 검사가 variant 로 먼저 고른 멤버 하나에 대고 이뤄지기 때문이다. 판별 속성이 없는 유니온은 겹치는 조합을 받는다.](/svg/discriminated_union_variant.svg)

```haskell
-- 리터럴 공통 속성(variant)으로 유니온을 가른다
data ModalProps = NoTitle                    -- variant: 'no-title'
                | Title { title :: String }  -- variant: 'title'

modal :: ModalProps -> Element
modal NoTitle   = div "No title"
modal (Title t) = div ("Title: " ++ t)       -- 이 분기 안에서 props 는 Title 로 좁혀진다

-- 초과 속성 검사도 variant 로 먼저 고른 멤버 하나에 대고 한다
check { variant = "no-title", title = "Oh dear" }   -- ✗ NoTitle 에 title 없음
check {}                                             -- ✗ variant 없음
-- 판별 속성이 없는 { a :: Int } | { b :: String } 은 { a = 1, b = "x" } 를 받는다 ("partial overlap")
```
