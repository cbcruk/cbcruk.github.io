![그래프 0–1, 0–2, 1–3, 1–4, 2–5 에서 0 부터 깊이 우선으로 돌면, 1 로 내려가 3, 4 를 끝까지 본 뒤 돌아와 2, 5 를 본다 — 0, 1, 3, 4, 2, 5. 재귀로 쓰면 콜 스택이 돌아올 자리를 기억하고, 명시적 스택으로 쓰면 이웃을 거꾸로 넣어 첫 이웃이 먼저 나오게 한다. 이미 방문한 노드는 건너뛴다.](/svg/dfs_order.svg)

```haskell
-- 깊이 우선: 한 갈래를 끝까지 내려간 뒤 돌아온다
dfs :: Graph -> Node -> [Node]
dfs g start = go [start] []
  where
    go []       seen = reverse seen
    go (n : st) seen
      | n `elem` seen = go st seen
      | otherwise     = go (g ! n ++ st) (n : seen)   -- 이웃을 앞에: 첫 이웃이 먼저 (JS 스택은 reverse 후 push)
-- 재귀로 쓰면 돌아올 자리를 콜 스택이 기억한다

graph = fromList [(0, [1, 2]), (1, [0, 3, 4]), (2, [0, 5]), (3, [1]), (4, [1]), (5, [2])]
dfs graph 0 == [0, 1, 3, 4, 2, 5]
```
