![selected 의 키마다 items 를 처음부터 훑으면 n × m 번이다. items 를 키로 한 번 Map 에 넣어 두면(n) 키마다 바로 꺼내(m) n + m 번이 된다 — Map 조회는 명세상 원소 수에 대해 선형보다 빠르다. React 에선 렌더 뒤 effect 에서 한 번에 만들고 ready 로 알린다. 10만 개가 넘으면 Web Worker 를 고려한다.](/svg/selected_map_index.svg)

```haskell
-- 대용량 목록에서 selected 키로 아이템 찾기
slow = [find ((== k) . key) items | k <- selected]   -- O(n × m)

index = Map.fromList [(key i, i) | i <- items]         -- 한 번 O(n)
fast  = mapMaybe (`Map.lookup` index) selected        -- O(m) — Map 조회는 선형보다 빠르다 (명세)

-- React: 렌더 뒤 effect 에서 한 번에 만들고 ready 로 알린다 (청크로 나누지 않는다)
useItemsIndex items = useEffect (setMap (index items) >> setReady True) [items]
-- 10만 개가 넘으면 Web Worker
```
