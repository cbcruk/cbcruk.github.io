CRA 는 `.env` 의 `${VAR}` 를 이미 있는 환경 변수로 채운다(dotenv-expand)[^229-expand] — turbo 가 태스크마다 넣어주는 `TURBO_HASH`[^229-turbo] 를 그대로 받아 쓴다.

```sh
# .env
REACT_APP_VERSION=0.0.0-${TURBO_HASH}
```

REACT_APP_VERSION을 자동으로 입력할 방법을 찾다가 결국 hash값을 추가했다.
