![CRA 는 .env 의 ${VAR} 를 이미 있는 환경 변수 값으로 채운다(dotenv-expand). turbo 는 태스크를 돌릴 때마다 그 태스크의 해시를 TURBO_HASH 로 넣어 주므로, REACT_APP_VERSION=0.0.0-${TURBO_HASH} 로 두면 버전이 자동으로 채워진다.](/svg/cra_env_turbo_hash.svg)

```haskell
-- CRA: .env 의 ${VAR} 를 이미 있는 환경 변수로 채운다 (dotenv-expand)
expand :: Env -> String -> String
expand env = replaceVars (\v -> fromMaybe "" (lookup v env))

-- turbo 가 태스크마다 TURBO_HASH 를 넣어 준다 — REACT_APP_VERSION 을 자동으로 채울 방법을 찾다가 해시를 붙였다
expand [("TURBO_HASH", "ab12")] "0.0.0-${TURBO_HASH}" == "0.0.0-ab12"   -- REACT_APP_VERSION
```
