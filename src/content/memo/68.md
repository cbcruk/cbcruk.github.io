![localtunnel 은 로컬 포트에 공개 URL 을 붙인다 — 배포나 DNS 설정 없이 남에게 보여 주거나 웹훅 같은 외부 콜백을 받을 때 쓴다. 서버가 listen 을 시작하면 그 포트로 터널을 연다. 다만 너무 느려서 ngrok 이나 cloudflared 가 현실적일 수 있다.](/svg/localtunnel_public_url.svg)

```haskell
-- 로컬 포트에 공개 URL — 배포·DNS 없이 보여 주거나 웹훅을 받을 때
tunnel :: Port -> Subdomain -> IO PublicUrl

main = listen port (tunnel port name)      -- app.listen(PORT, () => localtunnel({ port, subdomain }))
-- 너무 느렸다 → ngrok · cloudflared · localxpose (awesome-tunneling)
```
