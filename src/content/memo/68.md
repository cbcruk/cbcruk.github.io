[localtunnel](https://github.com/localtunnel/localtunnel)은 로컬 포트에 공개 URL 을 붙인다 — 배포나 DNS 설정 없이 남에게 보여주거나 외부 콜백(웹훅)을 받을 때.[^68-2]

```js
app.listen(PORT, async () => {
  const tunnel = await localtunnel({
    port: PORT,
    subdomain: name,
  })
})
```

> 하지만 너무 느려서 ngrok 쓰는게 현실적일수도 있겠다. -20220917
