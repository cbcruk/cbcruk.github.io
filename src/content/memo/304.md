![chrono 는 "Last Friday", "5 days ago", "17 August 2013 - 19 August 2013", ISO 8601 같은 글에서 날짜를 뽑는다. parse 는 기준 날짜로 컨텍스트를 만들고, 모든 파서를 돌려 결과를 모으고, 글 안의 위치로 정렬한 뒤, 리파이너로 겹치거나 이어지는 결과를 다듬는다. inclusive-dates 는 이 chrono 를 써서 자연어 입력을 받는 접근성 높은 데이트피커다 — locale·minDate·maxDate·referenceDate 를 넘긴다.](/svg/chrono_parse_pipeline.svg)

```haskell
-- chrono: 글에서 날짜를 뽑는다 ("Last Friday", "5 days ago", "17 Aug 2013 - 19 Aug 2013", ISO 8601…)
parse :: Reference -> String -> [Parsed]
parse ref text = refine                     -- 리파이너: 겹치거나 이어지는 결과를 합친다
               . sortOn index               -- 글 안의 위치 순
               . concatMap ($ ctx) parsers  -- 모든 파서를 돌려 모은다
  where ctx = context ref text              -- 기준 날짜(referenceDate)

-- inclusive-dates: chrono 위에 올린 접근성 높은 데이트피커
-- chronoParseDate text { locale, minDate, maxDate, referenceDate }
--   원 저장소는 maxDate 에 this.minDate 를 넘긴다 — this.maxDate 가 맞다
```
