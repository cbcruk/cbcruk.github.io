![delete obj.age 는 속성을 지우고 true 다. 없는 속성을 지워도 true. configurable: false 로 정의한 속성은 못 지워서 non-strict 에선 false, strict(모듈·클래스)에선 TypeError 다. 변수는 지울 수 없어 non-strict 에선 false, strict 에선 SyntaxError. 배열 요소를 지우면 길이는 그대로고 그 자리가 빈 칸(hole)이 된다 — 배열은 splice 를 쓴다.](/svg/js_delete_operator.svg)

```haskell
-- delete 는 configurable 한 자기 속성만 지운다
delete :: Mode -> Object -> Key -> Either Error Bool
delete _      o k | not (hasOwn o k)  = Right True          -- 없는 속성도 True
                  | configurable o k  = Right True          -- 지운다
delete Sloppy _ _                     = Right False         -- non-configurable
delete Strict _ _                     = Left TypeError      -- 모듈·클래스 안

-- 변수는 못 지운다: sloppy False · strict SyntaxError
delete Sloppy arr 1 == Right True    -- [1, <empty>, 3] 구멍이 남는다 → 배열은 splice
```
