![new Date(문자열) 이 모든 엔진에서 보장하는 건 2022-04-09T12:00:00 같은 ISO 형식뿐이다. 공백으로 가른 2022-04-09 12:00:00 은 구현 정의라 Safari 에서는 Invalid Date 가 됐다. 그런 형식은 date-fns 의 parse 에 형식 문자열을 명시해 읽는다.](/svg/date_parse_iso_only.svg)

```haskell
-- new Date(문자열): 엔진이 보장하는 건 ISO 형식뿐
newDate :: Engine -> String -> Maybe Date
newDate _      s | isIso s = Just (parseIso s)       -- "2022-04-09T12:00:00"
newDate Safari _           = Nothing                 -- "2022-04-09 12:00:00" → Invalid Date
newDate e      s           = implementationDefined e s

-- 형식을 명시해 읽는다: isAfter(new Date(), parse(DATE, 'yyyy-MM-dd HH:mm:ss', new Date()))
```
