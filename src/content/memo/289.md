Bottom Sheet 라이브러리 비교

**react-modal-sheet** 추천:
- 활발한 유지보수 (v5 최근 릴리즈)
- Motion(구 Framer Motion) 기반, Compound component 패턴
- `avoidKeyboard`, `disableDismiss` 등 유용한 옵션

```tsx
import { Sheet } from 'react-modal-sheet'

<Sheet isOpen={isOpen} onClose={() => setOpen(false)}>
  <Sheet.Container>
    <Sheet.Header />
    <Sheet.Content>콘텐츠</Sheet.Content>
  </Sheet.Container>
  <Sheet.Backdrop />
</Sheet>
```

> [!WARNING]
> react-spring-bottom-sheet는 마지막 릴리스가 v3.4.1(2022-06). 신규 프로젝트에선 피할 것.
