![react-modal-sheet 는 지금도 유지보수되고(v5) Motion 기반 compound component 로 쓰며 avoidKeyboard·disableDismiss 옵션이 있다. vaul 은 Radix Dialog 기반이지만 유지보수가 멈췄고, react-spring-bottom-sheet 는 마지막 릴리스가 2022년 6월 v3.4.1 이라 새 프로젝트에선 피한다.](/svg/bottom_sheet_choice.svg)

```haskell
-- Bottom Sheet: 먼저 유지보수되는가로 거른다
data Lib = Lib { name :: String, maintained :: Bool }

choose :: [Lib]
choose = filter maintained
  [ Lib "react-modal-sheet"         True    -- v5 · Motion 기반 compound · avoidKeyboard, disableDismiss
  , Lib "vaul"                      False   -- Radix Dialog 기반, 유지보수 중단
  , Lib "react-spring-bottom-sheet" False   -- 마지막 v3.4.1 (2022-06)
  ]
-- <Sheet isOpen onClose><Sheet.Container><Sheet.Header/><Sheet.Content/></Sheet.Container><Sheet.Backdrop/></Sheet>
```
