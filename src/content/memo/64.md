![xlsx 로 시트를 header: 1 로 읽으면 행이 객체가 아니라 배열로 나와 열을 인덱스로 자를 수 있다. 머리글 행을 빼고 2~4번째 열(키·영어·한국어)만 잘라, 빈 행은 [] 로 남으므로 걸러 내고, 키를 소문자·밑줄로 바꿔 en.json 과 ko.json 두 파일로 나눠 쓴다. CSV 와는 다르다.](/svg/xlsx_to_locale_json.svg)

```haskell
-- 엑셀 → 언어별 JSON. header: 1 이면 행이 배열 — 열을 인덱스로 자른다
locales :: [[Cell]] -> (Map Key String, Map Key String)
locales rows = (fromList [(k, en) | (k, en, _) <- rs], fromList [(k, ko) | (k, _, ko) <- rs])
  where rs = [ (normalize key, en, ko)
             | row <- drop 1 rows                       -- 머리글 행
             , let [key, en, ko] = take 3 (drop 1 row)  -- 2~4번째 열
             , any nonEmpty row ]                       -- 빈 행도 [] 로 나온다
        normalize = map toLower . replace "-" "_"
-- → en.json · ko.json
```
