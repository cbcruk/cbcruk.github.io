![useStateObject 는 객체 상태에 set·setItem·merge·reset 을 붙인 useState 래퍼다. Map·Set 에도 같은 걸 하려면 주의할 점이 하나 있다. 같은 Map 을 고쳐서 넘기면 Object.is 로 이전과 같은 값이라 React 가 갱신을 무시한다. 그래서 업데이트마다 new Map(prev) 로 복사한 뒤 고쳐서 넘긴다 — set·delete·clear 가 모두 이 update 를 거친다.](/svg/use_state_map_set.svg)

```haskell
-- useStateObject: 객체 상태에 편의 메서드를 붙인 useState 래퍼
type StateObject t = t & { set :: SetState t, setItem :: k -> t ! k -> IO (), merge :: Partial t -> IO (), reset :: IO () }

-- Map·Set 도 같은 식으로. 단 같은 Map 을 고쳐 넘기면 Object.is 로 같아 React 가 무시한다
update :: (Map k v -> IO ()) -> SetState (Map k v) -> IO ()
update f setMap = setMap $ \prev -> do
  let next = copy prev          -- new Map(prev): 매번 새 참조
  f next
  pure next

useStateMap init = { map, set = \k v -> update (insert k v), delete = update . delete
                   , clear = setMap empty, has, get, entries, size }
-- useStateSet 도 같은 모양: add · delete · has · clear
```
