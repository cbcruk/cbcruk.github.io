minified React new-window 컴포넌트의 자원 안전성(창 닫힘·interval 정리·이중 해제 없음)을 작은 상태 기계로 옮겨 Lean으로 증명. 핵심은 boolean 필드 `released` 하나.

```lean
/-- 정리 1 — 멱등성.  release ∘ release = release
    polling·beforeunload·close 세 트리거가 와도 결과는 1회 적용과 같다. -/
theorem release_idem (s : St) : release (release s) = release s := by
  unfold release
  by_cases h : s.released <;> simp [h]

/-- 정리 1' — 반복 불변.  ∀n. release^(n+1) = release
    n번 호출해도 1번과 같다 (세 트리거 → 임의 횟수로 일반화). -/
theorem release_iter (s : St) (n : ℕ) :
    release^[n + 1] s = release s := by
  induction n with
  | zero => rfl
  | succ k ih => rw [Function.iterate_succ_apply, ih]; exact release_idem s

/-- 정리 2 — 자원 보존.  #{ clearInterval 발화 } ≤ 1
    Open 상태에서 release 트리거가 아무리 많이 와도 clearInterval 은 최대 1회.
    근거는 단조성: released(s) ⟹ released(release s) — 한 번 켜지면 영원히 켜짐. -/
theorem clear_called_at_most_once (evs : List Ev)
    (hrel : ∀ e ∈ evs, e = Ev.userClose ∨ e = Ev.beforeunload ∨ e = Ev.unmountClose) :
    (runClears opened evs).2 ≤ 1 := by
  -- 첫 release 가 released:=true 로 만든 뒤부터 firesClear 는 항상 false
  sorry  -- 증명 스케치: opened.released=false 라 첫 트리거만 hit=1,
         -- 그 후 모든 상태에서 released=true → firesClear=false → hit=0

/-- 정리 3 — mount 가드.  windowOpen(s) ⟹ mount(s) = s
    Open 상태에서 mount 는 멱등 (중복 open 없음). -/
theorem mount_idem_when_open (s : St) (h : s.windowOpen) :
    mount s = s := by
  unfold mount; simp [h]

/-- 정리 4 — 종착 배타.  ¬windowOpen(s′) ⊕ staticLeft(s′)
    창이 닫혔으면 정적 스냅샷은 없고, 그 역도 성립 (두 종착 상태 상호 배타). -/
theorem unmount_branches_exclusive (c : Bool) (s : St) (h : ¬ s.staticLeft) :
    let s' := unmount c s
    (s'.windowOpen = false ∧ s'.staticLeft = false) ∨
    (s'.windowOpen = s.windowOpen ∧ s'.staticLeft = true) := by
  unfold unmount release
  cases c <;> simp_all <;> by_cases hr : s.released <;> simp [hr]
```

정리 2의 `sorry`는 단조성 보조정리(한 번 `released`면 영원히 `released`) 하나면 닫힌다 — `#발화 ≤ 1`은 그 단조성의 따름정리.
