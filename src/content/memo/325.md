거리 만km 포맷팅 — `toFixed(1)` 은 반올림하고 0 까지 채운 문자열을 준다(`100000` → `10.0만km`)[^tofixed]

```typescript
function formatToManKm(distance: number): string {
  const manKm = (distance / 10000).toFixed(1)

  return `${manKm}만km`
}

formatToManKm(104335) // "10.4만km"
```

---

[^tofixed]: [Number.prototype.toFixed() - MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number/toFixed): *"The number is rounded if necessary, and the fractional part is padded with zeros if necessary so that it has the specified length."*
