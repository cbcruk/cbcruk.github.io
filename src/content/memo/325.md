![거리를 1만으로 나눈 뒤 toFixed(1) 로 소수 첫째 자리까지 반올림한 문자열을 만들어 만km 를 붙인다. 104335 는 10.4만km. toFixed 는 자릿수를 0 으로 채우므로 100000 은 10만km 가 아니라 10.0만km 가 된다.](/svg/man_km_format.svg)

```haskell
-- 거리 → 만km. toFixed(1): 반올림하고 0 까지 채운 문자열
formatToManKm :: Double -> String
formatToManKm d = showFFloat (Just 1) (d / 10000) "만km"

formatToManKm 104335 == "10.4만km"
formatToManKm 100000 == "10.0만km"   -- 10만km 가 아니다
```
