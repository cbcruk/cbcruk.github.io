webpack 은 `.mjs` 를 `javascript/esm` 으로 고정해 CommonJS 를 막는다[^292-esm] — `type` 을 직접 주면 그 기본 규칙을 건너뛴다[^292-type].

```js
configureWebpack: {
    module: {
      rules: [
        {
          test: /\.mjs$/,
          include: /node_modules/,
          type: 'javascript/auto',
        },
      ],
    },
  },
```

---

[^292-esm]: [Module Methods | webpack](https://webpack.js.org/api/module-methods/): *"`.mjs` or `.js` with `"type": "module"` in `package.json`"* → *"No CommonJS allowed, for example, you can't use `require`, `module.exports` or `exports`"*. webpack 4 기본 규칙: [`{ test: /\.mjs$/i, type: "javascript/esm" }`](https://github.com/webpack/webpack/blob/v4.47.0/lib/WebpackOptionsDefaulter.js#L66-L67)
[^292-type]: [Module | webpack](https://webpack.js.org/configuration/module/#ruletype): *"`Rule.type` sets the type for a matching module. This prevents defaultRules and their default importing behaviors from occurring."*
