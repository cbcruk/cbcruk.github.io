![webpack 은 .mjs 파일을 javascript/esm 으로 다뤄 require·module.exports 같은 CommonJS 를 막는다. node_modules 의 .mjs 가 CommonJS 를 섞어 쓰면 빌드가 깨지므로, 규칙에 type: javascript/auto 를 직접 주면 기본 규칙을 건너뛰고 둘 다 허용한다.](/svg/webpack_mjs_auto.svg)

```haskell
-- webpack: .mjs 는 javascript/esm — CommonJS(require·module.exports) 금지
moduleType :: [Rule] -> File -> ModuleType
moduleType rules f = case find (`matches` f) rules of
  Just r | Just t <- ruleType r -> t        -- type 을 직접 주면 기본 규칙을 건너뛴다
  _ | ".mjs" `isSuffixOf` f      -> JavascriptEsm
    | otherwise                  -> JavascriptAuto

-- { test: /\.mjs$/, include: /node_modules/, type: 'javascript/auto' }
```
