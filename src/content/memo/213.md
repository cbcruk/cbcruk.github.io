![npm 은 지금 실행 중인 스크립트 이름을 npm_lifecycle_event 환경 변수로 넘긴다. dev:hello 스크립트에서 ${npm_lifecycle_event#dev:} 로 접두사를 떼면 hello 가 남는다. 스크립트는 sh 로 돌기 때문에 bash 전용 ${var//a/b} 대신 POSIX ${var#prefix} 를 쓴다. 다만 이렇게 하기보다 스크립트를 따로 쓰는 편이 낫다.](/svg/npm_lifecycle_event_prefix.svg)

```haskell
-- npm 은 실행 중인 스크립트 이름을 npm_lifecycle_event 로 넘긴다
stage :: String -> Maybe String
stage = stripPrefix "dev:"       -- ${npm_lifecycle_event#dev:} — sh 로 돌아서 POSIX # 만 (bash 의 // 는 안 된다)

stage "dev:hello" == Just "hello"
-- 이렇게 하기보다 스크립트를 따로 쓰는 게 낫다
```
