![다중 선택 필터에서 선택된 개수는 JS 없이 CSS 카운터로 센다. 컨테이너에서 counter-reset 으로 0 부터 시작하고, :checked 인 항목마다 counter-increment 로 하나씩 올리고, ::after 의 content: counter(filters) 로 보여 준다. 모바일 판별은 @media (pointer: coarse) 로 한다.](/svg/css_counter_checked.svg)

```haskell
-- web.dev 글은 다중 선택을 checkbox · select 두 방식으로 만든다. 여기 남긴 건 그 곁의 개수 세기·모바일 판별
-- 선택 개수: JS 없이 CSS 카운터로
filters :: [Input] -> Int
filters = length . filter checked     -- counter-reset → :checked 마다 counter-increment
-- aside::after { content: counter(filters) }
-- 모바일 판별: @media (pointer: coarse)
```
