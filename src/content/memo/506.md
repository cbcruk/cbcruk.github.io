![iframe 이 로드되면(이미 complete 면 바로) contentDocument.body 를 마운트 지점으로 잡고 createPortal 로 children 을 그 안에 그린다. 간단히는 react-frame-component 가 이걸 해 준다. iframe 안에는 부모 CSS 가 적용되지 않아 스타일을 따로 넣어야 하고, DOM 이벤트는 iframe 밖으로 버블링되지 않는다. 다만 React 핸들러는 portal 이라 DOM 이 아니라 React 트리를 따라 부모 컴포넌트로 올라온다. 스타일 격리만 원하면 Shadow DOM 이 더 가볍다.](/svg/iframe_portal_render.svg)

```haskell
-- iframe 안에 컴포넌트를 그린다: iframe 의 body 로 portal
iframeRenderer children = do
  mount <- onLoad iframe (body . contentDocument)   -- 이미 readyState == "complete" 면 바로
  pure [iframe, maybe empty (portal children) mount]
-- 간단히는 react-frame-component: <Frame head={style}>…</Frame>

-- 경계가 둘이다
css      (inside iframe) == []        -- 부모 CSS 미적용, 스타일을 따로 넣는다
bubbles  domEvent        == False     -- DOM 이벤트는 iframe 밖으로 안 나간다
bubbles  reactEvent      == True      -- portal 이라 React 트리를 따라 부모로 올라온다
-- 스타일 격리만이면 Shadow DOM
```
