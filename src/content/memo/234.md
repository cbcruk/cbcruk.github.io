리눅스는 사용자당 inotify 감시 개수에 상한(`max_user_watches`)이 있다[^234-inotify] — 모자라면 webpack 이 변경을 못 알아챈다[^234-webpack].

```bash
# `System limit for number of file watchers reached`

echo fs.inotify.max_user_watches=524288 | sudo tee -a /etc/sysctl.conf && sudo sysctl -p
```

- [Watch and WatchOptions | webpack](https://webpack.js.org/configuration/watch/#not-enough-watchers)

[^234-inotify]: [inotify(7) - Linux manual page](https://man7.org/linux/man-pages/man7/inotify.7.html): *"/proc/sys/fs/inotify/max_user_watches This specifies an upper limit on the number of watches that can be created per real user ID."*
[^234-webpack]: [Watch and WatchOptions | webpack](https://webpack.js.org/configuration/watch/#not-enough-watchers): *"Verify that you have enough available watchers in your system. If this value is too low, the file watcher in Webpack won't recognize the changes"*
