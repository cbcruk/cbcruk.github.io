![리눅스는 사용자당 만들 수 있는 inotify 감시 개수에 상한(max_user_watches)이 있다. 파일이 많아 상한을 넘으면 System limit for number of file watchers reached 가 나고 webpack 의 파일 감시가 변경을 알아채지 못한다. /etc/sysctl.conf 에 fs.inotify.max_user_watches=524288 을 넣고 sysctl -p 로 적용한다.](/svg/inotify_max_watches.svg)

```haskell
-- inotify: 사용자당 감시 개수에 상한이 있다
watched :: [File] -> Bool
watched files = length files <= maxUserWatches   -- 넘으면 webpack 이 변경을 못 알아챈다
                                                 -- "System limit for number of file watchers reached"
-- echo fs.inotify.max_user_watches=524288 | sudo tee -a /etc/sysctl.conf && sudo sysctl -p
```
