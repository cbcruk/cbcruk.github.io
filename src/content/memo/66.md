```sh
# 특정 패키지에 모듈을 설치해야한다면
yarn workspace <workspace_name> <command>
```

`<command>` 자리에 아무 Yarn 명령이나 오고 그 워크스페이스 안에서 돈다 — `add` 면 그 패키지의 `package.json` 에 들어간다.[^66-workspace]

---

[^66-workspace]: [yarn workspace | Yarn](https://classic.yarnpkg.com/en/docs/cli/workspace): *"This will run the chosen Yarn command in the selected workspace."* / `yarn workspace awesome-package add react react-dom --dev` — *"will add `react` and `react-dom` as `devDependencies` in your `packages/awesome-package/package.json`."*
