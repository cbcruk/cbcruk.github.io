![모노레포에서 yarn workspace <이름> <명령> 은 아무 Yarn 명령이나 그 워크스페이스 안에서 실행한다. add 면 루트가 아니라 그 패키지의 package.json 에 의존성이 들어간다.](/svg/yarn_workspace_command.svg)

```haskell
-- 아무 Yarn 명령이나 그 워크스페이스 안에서
workspace :: Name -> Command -> IO ()
workspace name cmd = inDir (packageDir name) (yarn cmd)

workspace "awesome-package" (Add ["react", "react-dom"] Dev)   -- 그 패키지의 package.json devDependencies 에
```
