![select 에는 placeholder 속성이 없다. 값이 빈 문자열인 첫 option 을 두고 disabled 로 다시 고르지 못하게, hidden 으로 목록에서 숨긴다. required 이면 스펙상 그 option 이 placeholder label option 이 되어 고르지 않고 제출하면 막힌다. React 에서는 option 의 selected 대신 select 의 defaultValue="" 로 처음에 그것을 고른다.](/svg/select_placeholder_option.svg)

```haskell
-- select 에는 placeholder 가 없다 → 값이 "" 인 첫 option 이 그 노릇을 한다
placeholderOption :: String -> Option
placeholderOption label = Option { value = "", disabled = True, hidden = True, text = label }

valid :: Select -> Bool
valid s = not (required s) || value s /= ""    -- required 면 placeholder label option 으로는 제출이 막힌다

-- React: <option selected> 대신 <select defaultValue="">
```
