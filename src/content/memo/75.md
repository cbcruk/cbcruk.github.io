![WSL 의 .zshrc 에서 HOME 을 Windows 사용자 폴더(/mnt/c/Users/…)로 두고, 셸이 홈에서 열렸으면 그 아래 Downloads 로 바로 이동한다.](/svg/wsl_zsh_start_dir.svg)

```haskell
-- WSL .zshrc: HOME 을 Windows 사용자 폴더로, 홈에서 열리면 Downloads 로
home = "/mnt/c/Users/cbcru"

startDir :: Path -> Path
startDir pwd = if pwd == home then home </> "Downloads" else pwd
```
