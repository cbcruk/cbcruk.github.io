![dangerouslySetInnerHTML 은 DOM 노드의 innerHTML 을 덮어쓴다. innerHTML 로 넣은 script 요소는 실행되지 않지만, img 의 onload·onerror 같은 이벤트 핸들러 속성은 이미지가 로드되면 그대로 실행된다. 꼭 필요할 때 쓰는 우회이자, 사용자 입력을 넣으면 그대로 XSS 가 되는 이유다.](/svg/inner_html_event_handlers.svg)

```haskell
-- dangerouslySetInnerHTML = innerHTML 덮어쓰기
runs :: Injected -> Bool
runs (ScriptTag _)       = False    -- innerHTML 로 넣은 <script> 는 실행되지 않는다
runs (HandlerAttr _ _)   = True     -- <img onload="…"> · onerror — 로드되면 실행된다

-- 꼭 필요할 때 쓰는 우회 · 같은 이유로 사용자 입력을 넣으면 XSS
```
