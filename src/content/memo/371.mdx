![b.module.css 의 클래스 b 를 @value b from "./b.module.css" 로 가져오면, 이 파일의 :global(.b) 안 b 가 그 모듈의 해시된 클래스(._b_15lvz_1)로 바뀐다 — @value 는 선언 값뿐 아니라 규칙의 셀렉터에서도 치환되기 때문이다. @value 줄이 없으면 문자 그대로 .b 라 아무것도 잡지 못한다.](/svg/css_modules_value_selector.svg)

```haskell
-- @value 로 가져온 이름은 선언 값뿐 아니라 셀렉터 안에서도 치환된다
replaceSymbols :: Map Name String -> Rule -> Rule
replaceSymbols defs (Rule sel decls) = Rule (subst defs sel) (map (subst defs) decls)
                                       -- icss-utils: decl 뿐 아니라 rule.selector 도 돈다

defs = fromList [("b", "_b_15lvz_1")]   -- @value b from "./b.module.css"
replaceSymbols defs ".root :global(.b)" == ".root ._b_15lvz_1"   -- 다른 모듈의 해시된 클래스
replaceSymbols empty ".root :global(.b)" == ".root .b"           -- @value 없으면 아무것도 안 잡힌다
```
