Exporting values variables
</QuoteLink>

```css
@value b from "./b.module.css";

.root {
  color: aquamarine;
}

.root :global(.b) {
  text-decoration: line-through;
}
```


`@value` 로 가져온 이름은 선언 값뿐 아니라 셀렉터 안에서도 치환된다[^icss-selector] — 다른 모듈의 클래스 `b` 를 가져오면 `:global(.b)` 가 그 모듈의 해시된 클래스(`._b_15lvz_1`)가 된다. `@value` 줄이 없으면 문자 그대로 `.b` 라 아무것도 안 잡힌다.

---

[^icss-selector]: [icss-utils `replaceSymbols.js`](https://github.com/css-modules/icss-utils/blob/c4e53fefa32df5db7786dd0fc6f053963f12ea02/src/replaceSymbols.js#L7-L11) — `postcss-modules-values` 가 모은 정의를 이 함수로 치환하는데, 선언(`decl`)뿐 아니라 규칙의 셀렉터(`rule.selector`)도 돈다.
