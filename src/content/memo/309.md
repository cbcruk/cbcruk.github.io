![Enzyme 은 컴포넌트 인스턴스의 state·props 를 직접 읽었지만 React Testing Library 는 화면만 본다. 그래서 테스트 환경에서만 props 와 state 를 JSON 으로 pre 에 렌더하고 getByTestId 로 그 텍스트를 읽어 비교했다. 구현 세부를 화면에 내보내는 우회라 Enzyme 제거라는 목표만 달성한 임시 방편이다.](/svg/enzyme_to_rtl_debug_pre.svg)

```haskell
-- Enzyme → RTL: RTL 은 화면만 본다. 그래서 테스트에서만 state·props 를 화면에 찍는다
debug :: Env -> Props -> State -> Maybe Html
debug Test props state = Just (pre "ThumbnailDebug" (encode (props, state)))
debug _    _     _     = Nothing

-- 테스트: decode (textOf (getByTestId "ThumbnailDebug"))
-- 구현 세부를 화면에 내보내는 우회 — Enzyme 제거라는 목표만 달성한 임시 방편
```
