![어디서든 add 를 부르면 setter 가 새 배열을 만들고 changed 를 발행한다. React 는 getSnapshot 으로 다시 읽어 이전 값과 Object.is 로 비교해 다르면 리렌더, 같으면 건너뛴다. getter 는 내부 배열을 그대로 돌려주므로 안 바뀌면 같은 참조다. getSnapshot 이 매번 새 배열을 만들면 항상 달라 무한 루프가 된다.](/svg/external_store_flow.svg)

```haskell
-- React 밖 상태: 변경과 발행을 setter 한 곳에 둔다 (add·remove 도 전부 여기를 지난다)
set :: Store -> [Toast] -> IO ()
set store xs = do
  writeRef (toasts store) (copy xs)   -- 새 참조 = "바뀌었다"
  emit store Changed

getSnapshot :: Store -> IO [Toast]
getSnapshot = readRef . toasts        -- 새로 만들지 않는다: 같은 참조면 안 바뀐 것

-- Changed 마다 getSnapshot 을 불러 이전 값과 Object.is 로 비교, 다를 때만 리렌더
useSyncExternalStore :: Subscribe -> IO a -> a

-- 법칙: 안 바뀌었으면 getSnapshot 두 번이 같은 참조. 매번 새 값이면 무한 루프
```
