![O 의 actions 안 b 만 선택 속성으로 바꾸려면, 바깥에서 Omit 으로 actions 를 빼고, 같은 키 actions 를 매핑 타입으로 다시 붙이면서 그 안쪽을 Omit(b) & Partial(Pick(b)) 로 만든다. 결과는 actions 가 { a: string; b?: number }. 덮어쓰기는 안쪽을 Omit(덮을 키) & 새 타입으로. 한두 곳에만 쓸 거면 손으로 쓰는 게 더 명확하다. 값을 바꿀 때도 라이브러리 객체를 직접 고치지 말고 펼쳐서 새로 만든다.](/svg/nested_type_override.svg)

```haskell
-- 중첩 객체 타입의 안쪽만 바꾼다: 바깥에서 K 를 빼고, 같은 키로 다시 붙이며 안쪽을 고친다
type NestedOptional t k ok = Omit t k & { k :: Omit (t ! k) ok & Partial (Pick (t ! k) ok) }
type OverrideNested t k o  = Omit t k & { k :: Omit (t ! k) (keyof o) & o }

type O = { actions :: { a :: String, b :: Number } }
NestedOptional O "actions" "b"          == { actions :: { a :: String, b :: Maybe Number } }
OverrideNested O "actions" { b :: Bool } == { actions :: { a :: String, b :: Bool } }

-- 한두 곳이면 손으로 쓰는 게 더 명확하다. 반복될 때만 유틸리티
-- 값도 같은 방식으로: 라이브러리 객체를 변이하지 말고 펼쳐서 새로
modified = info { actions = (actions info) { onDownload = Nothing } }
```
