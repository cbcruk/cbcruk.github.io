![공유할 게 로딩 UI 라는 동작뿐이면 그것만 스타일 없는 LoadingButton 으로 뽑는다. disabled 이면 Spinner 를 겹쳐 띄우고 Label 은 invisible 로 자리만 지킨다. 스타일은 className 으로 호출부가 정하고, 다르게 배치하고 싶으면 children 을 함수로 넘겨 Spinner·Label 을 직접 조립한다.](/svg/unstyled_loading_button.svg)

```haskell
-- 공유할 게 동작(로딩 UI)뿐이면 그것만 뽑는다 — 스타일은 호출부가
data Children = Render (() -> Html) | Node Html

loadingButton :: Bool -> Children -> Html
loadingButton _        (Render f) = button (f ())                      -- 호출부가 Spinner·Label 을 조립
loadingButton disabled (Node c)   = button ([spinner | disabled]        -- absolute inset-0 로 겹친다
                                        ++ [label (invisibleIf disabled) c])  -- 자리를 지켜 폭이 안 흔들린다
-- LoadingButton.Spinner = spinner · LoadingButton.Label = label · className 은 그대로 넘긴다
```
