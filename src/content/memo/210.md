![npm view 는 설치하지 않고 레지스트리에서 패키지 정보를 읽는다. versions 필드는 게시된 모든 버전 목록이고, time 필드는 버전마다 게시된 시각이다.](/svg/npm_view_fields.svg)

```haskell
-- 설치하지 않고 레지스트리 메타데이터를 읽는다
npmView :: Package -> Field -> IO Json
npmView "cowsay" "versions"   -- 게시된 모든 버전
npmView "cowsay" "time"       -- 버전마다 게시된 시각
```
