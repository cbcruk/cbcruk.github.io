![x 를 0 에서 100 으로 보내는 업데이트 하나에 끝을 알리는 길이 둘 있다. onRest 는 애니메이션이 물리적으로 멈췄을 때 불려 화면 상태(예: stopped)를 바꾸는 데 쓴다. onResolve 는 그 업데이트의 Promise 가 풀릴 때 불려 비동기 흐름을 잇는 데 쓴다. api.start 가 그 Promise 를 돌려주므로 await 로 기다려도 된다.](/svg/react_spring_onrest_onresolve.svg)

```haskell
-- react-spring 업데이트의 끝을 알리는 두 길
start :: Update -> Promise Result               -- api.start({ x: 100 })

onRest    :: Result -> IO ()   -- 물리적으로 멈췄을 때 → 화면 상태 (setStatus "stopped")
onResolve :: Result -> IO ()   -- 업데이트의 Promise 가 풀릴 때 → 비동기 흐름 제어

-- onResolve 대신 await 로 같은 자리를 기다린다
flow = do
  _ <- start { x = 100 }
  next
```
